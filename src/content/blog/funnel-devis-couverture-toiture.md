# Funnel de devis couverture et toiture : tuiles, ardoise, zinc, étanchéité, brief, espace prospect

Un particulier, un syndic ou un gestionnaire de parc ouvre votre page. Il a une fuite, une toiture fatiguée, ou un projet de réfection. Il clique sur **Demander un devis**.

Puis il écrit : « Bonjour, tarif pour toiture. »

Pas de type d'intervention (tuiles, ardoise, zinc, bac acier, étanchéité terrasse…). Pas de surface ni de nombre de pans. Pas de pente. Pas d'accès. Pas d'état existant. Pas de photos. Pas de distinction urgence fuite vs projet planifié. Votre couvreur / technico rappelle. On reconstruit le brief. Parfois on se déplace pour découvrir un accès nacelle obligatoire, une charpente à reprendre, ou un syndic qui n'a pas encore voté. Parfois le prospect a déjà choisi un couvreur qui avait posé les bonnes questions dès le premier écran.

Ce n'est pas seulement un sujet commercial. C'est un sujet d'**entrée**.

Cette page explique comment un **funnel de devis couverture / toiture** transforme une demande vague en **brief chiffrable** : type d'intervention, surface ou pans, pente / accès, état existant, charpente visible, photos, urgence vs projet, type de client, options, puis espace prospect. Public : entreprises de couverture, zingueurs, étancheurs, artisans rénovation toiture, réseaux et agences qui outillent ces équipes.

## Définition : devis couverture / toiture (ce qu'il doit contenir)

Un **devis couverture** (toiture, zinguerie, étanchéité) est une proposition chiffrée tenant compte au minimum de :

- le **type d'intervention** (tuiles, ardoise, zinc, bac acier, étanchéité terrasse / toit plat, réfection partielle vs totale, dépannage fuite) ;
- une **surface approximative** (m²) ou un **nombre de pans** / indication de complexité ;
- la **pente** et l'**accès** (échafaudage, nacelle, rue étroite, hauteur, mitoyenneté) ;
- l'**état existant** (couverture fatiguée, sous-toiture, infiltrations connues) ;
- la **charpente** (visible / non visible / doute / reprise éventuelle à confirmer en visite) ;
- les **photos** (toiture, gouttières, accès, dégâts intérieurs si fuite) ;
- le **contexte** : urgence fuite vs projet planifié ;
- le **type de client** (particulier, pro, syndic / copropriété, bailleur) ;
- les **options** (zinguerie, isolation sous rampant associée, démoussage, évacuation gravats, échafaudage inclus ou non) ;
- une **mention générique** d'éventuels dispositifs ou aides si le prospect en parle (sans inventer de barème, de prime CEE, de MaPrimeRénov' chiffrée, ni de prix « officiel » au m²).

Sans type d'intervention, accès et un minimum de surface / pans (même approximatifs), vous n'avez pas un devis : vous avez une fourchette marketing.

## Pourquoi le formulaire contact casse ce secteur

La couverture cumule urgence (fuite), technique (pente, support, étanchéité), accès chantier et souvent multi-décideurs (syndic, conjoint, assureur). Un textarea « message » produit :

- des leads hors zone ou hors compétence (hauteur, amiante suspectée, monument, etc.) ;
- des demandes « prix au m² » impossibles à tenir sans brief ;
- des déplacements inutiles faute de photos toiture / accès ;
- des dossiers « urgence » traités comme des projets longs (ou l'inverse) ;
- des allers-retours sur les aides ou l'assurance (le prospect veut un chiffre garanti, vous ne pouvez pas le coller dans un wizard public).

## Questions à poser dans le funnel (sans noyer le prospect)

Trop de questions tue la conversion. Trop peu tue le chiffrage. Compromis fréquent pour un couvreur / entreprise de toiture :

### Étape cœur (obligatoire)

1. Type de client : particulier, entreprise, syndic / copropriété, bailleur / autre.
2. Contexte : urgence fuite / infiltration, réfection partielle, réfection totale, entretien / démoussage, « je ne sais pas / conseil ».
3. Type de couverture / intervention : tuiles, ardoise, zinc, bac acier, étanchéité terrasse / toit plat, mixte / autre.
4. Surface approximative (m²) **ou** nombre de pans / « je ne sais pas / à métrer ».
5. Accès chantier : facile, échafaudage, nacelle, contrainte rue / voisinage, hauteur.
6. Code postal (zone d'intervention).
7. Délai souhaité (urgent / sous 2 semaines / saison / projet distant / vote syndic).
8. Photos toiture / accès / dégâts ou « je n'ai pas encore de photo ».

### Étape technique (secondaire, ou après score Hot)

- Pente approximative (faible / moyenne / forte / je ne sais pas).
- État existant (qualitatif) : couverture ancienne, sous-toiture douteuse, gouttières HS, etc.
- Charpente visible / non visible / doute (sans transformer le funnel en diagnostic structure).
- Zinguerie associée (noues, faîtages, gouttières) : oui / non / à étudier.
- Isolation sous rampant ou combles associée : oui / non / à étudier (renvoi possible vers un parcours [isolation / ITE](https://www.quotebuilder.co/secteurs/funnel-devis-isolation-thermique-ite) si vous le proposez).
- Contexte assurance / sinistre : « oui / non / je ne sais pas » (collecte, pas de montage juridique dans le wizard).

### Étape contact

Identité, téléphone, créneau de rappel. Pour du B2B / syndic : SIRET, site, contact technique, éventuel conseil syndical / AMO.

Les options non choisies restent proposables plus tard en [variante](https://www.quotebuilder.co/blog/options-variantes-alternatives-devis-b2b), sans réécrire tout le devis.

## Urgence fuite vs projet planifié : deux vitesses, un funnel

Ne créez pas deux sites. Créez une **branche précoce** « contexte ».

| Branche | Priorité funnel | Suite typique |
|---------|-----------------|---------------|
| Urgence fuite | Photos dégâts + localisation + accès + créneau rappel court | Dépannage / mise en sécurité puis devis réfection |
| Réfection partielle | Zone concernée, pans, photos, état | Visite ciblée + devis |
| Réfection totale | Surface / pans, type couverture, accès, délai | Étude + devis + options |
| Entretien / démoussage | Surface, accès, état | Devis plus simple, score Warm souvent |

Le scoring change. Le process devis (dossier, validation, envoi, relance) reste le même.

## Aides, assurance, DTU, prix au m² : ce qu'il ne faut pas inventer

Les prospects demandent souvent : « Combien au m² ? », « C'est pris en charge par l'assurance ? », « Il y a une aide ? », « C'est conforme DTU ? ».

Dans un funnel public, la posture saine est :

- **ne pas afficher** de barèmes d'aides, primes, CEE, MaPrimeRénov' inventés ;
- **ne pas afficher** de prix au m² « officiels » ou de forfaits DTU chiffrés comme vérité nationale ;
- **mentionner** qu'une visite / un métré peut être nécessaire, et que des dispositifs ou un parcours assurance peuvent exister selon le cas ;
- **collecter** les infos utiles (sinistre déclaré oui/non, type de client, photos) pour qu'un humain traite ;
- **clarifier** que le devis travaux est distinct d'un montage d'aides ou d'un rapport d'expertise.

Promettre un montant d'aide ou un prix figé sans brief crée des litiges. Même logique que sur le [funnel isolation / ITE](https://www.quotebuilder.co/secteurs/funnel-devis-isolation-thermique-ite) et le [funnel pompe à chaleur / chauffage](https://www.quotebuilder.co/secteurs/funnel-devis-pompe-chaleur-chauffage) : générique oui, barème inventé non.

## Parcours type : du clic au dossier partagé

### 1. Entrée (Ads, SEO, QR chantier, partenaires, assureurs)

Landing secteur ou widget. Pas un textarea. Wizard 8-11 étapes max.

### 2. Configuration guidée

Branches Si/Alors (particulier vs pro vs syndic ; urgence vs projet ; tuiles vs zinc vs étanchéité ; accès simple vs nacelle). Catalogue de gammes / forfaits pose / options zinguerie. Le commercial retrouve les mêmes lignes en interne. Voir [bibliothèque de lignes et kits](https://www.quotebuilder.co/blog/bibliotheque-lignes-kits-devis-b2b).

### 3. Score et assignation

Hot si type d'intervention + surface/pans ou photos + urgence ou délai proche + zone OK. Warm si incomplet mais sérieux. Cold si « juste un prix au m² » hors zone ou projet non voté sans horizon. Owner clair, SLA de réponse (surtout sur fuite). Voir [délai de réponse](https://www.quotebuilder.co/blog/delai-reponse-demande-devis-b2b) et [assignation / SLA](https://www.quotebuilder.co/blog/assignation-sla-demande-devis-equipe).

### 4. Chiffrage

Estimateur assemble depuis le catalogue / forfaits. Options visibles (zinguerie, échafaudage, évacuation, isolation associée). Prix HT cohérents. Mention « sous réserve de visite / métré » quand c'est votre politique.

Avant envoi, une [validation interne](https://www.quotebuilder.co/blog/validation-interne-avant-envoi-devis-b2b) (technique + marge) évite les devis toiture sortis trop tôt avec accès mal cadré.

### 5. Envoi + espace prospect

Lien magique : récap, options, questions, documents (photos toiture, plan, constat). Le prospect n'a pas à chercher le bon PDF. Voir [envoyer devis lien vs PDF](https://www.quotebuilder.co/blog/envoyer-devis-lien-securise-vs-pdf-email) et [espace prospect](https://www.quotebuilder.co/blog/espace-prospect-devis-en-ligne).

Sur les comptes multi-décideurs (syndic, acheteur pro), le circuit de relecture côté client compte autant que le brief. Voir [approbation client multi-décideurs](https://www.quotebuilder.co/blog/approbation-client-multi-decideurs-devis-b2b).

### 6. Relances

Séquence adaptée au score et à l'urgence. Le dossier reste sur le lien de l'espace prospect. Quand le client a tranché, le commercial met à jour le statut du devis.

## Photos, accès chantier et visite

Le funnel ne remplace pas toujours la visite / le métré. Il **filtre** :

- dossiers incomplets ou hors zone → Cold / nurturing ;
- dossiers Hot avec photos exploitables → chiffrage indicatif puis visite courte ;
- dossiers complexes (copropriété, hauteur, mitoyenneté, charpente douteuse, amiante suspectée) → visite / étude avant devis ferme.

Clarifiez dans le parcours : « devis indicatif sous réserve de visite / métré » vs « devis ferme ». Ça évite les litiges sur les m² réels, les points singuliers ou le coût d'accès.

Sans photo d'accès, vous multipliez les déplacements inutiles. ## Tuiles, ardoise, zinc, bac acier, étanchéité : une branche, pas cinq sites

Beaucoup d'entreprises font plusieurs familles. Évitez cinq landings qui se cannibalisent sans brief commun. Une branche précoce « type d'intervention » suffit :

| Branche | Infos critiques |
|---------|-----------------|
| Tuiles | m² ou pans, pente, état, faîtage / noues |
| Ardoise | m² ou pans, type pose, accès, état support |
| Zinc / zinguerie | linéaires / zones, noues, gouttières, raccordements |
| Bac acier | surface, pente, isolation associée éventuelle, accès |
| Étanchéité terrasse / toit plat | m², complexité relevés, évacuations, accès |

Le scoring et le catalogue changent. Le process devis reste le même.

## Options fréquentes à proposer (sans 15 écrans)

Regroupez plutôt que de multiplier les étapes :

- échafaudage / nacelle (inclus, option, ou « selon visite ») ;
- zinguerie (gouttières, descentes, noues, faîtages) ;
- évacuation gravats / benne ;
- démoussage / entretien (si pertinent) ;
- isolation sous rampant / combles associée ;
- mise en sécurité / bâche (surtout urgence) ;
- reprise points singuliers (cheminée, velux, rives).

Affichez-les comme options cochables. Le total bouge. Le prospect comprend. Vous évitez le « surprise chantier ».

## Délai de pose, validité et acomptes

Trois leviers à lier :

1. **Validité du devis** (ex. 30 jours) : matériaux et planning bougent. Voir [validité / expiration](https://www.quotebuilder.co/blog/validite-expiration-devis-b2b).
2. **Créneau chantier** : réservé quand le dossier est gagné et que l'acompte est reçu, pas sur un devis « peut-être » (surtout en saison ou après orage).
3. **Acompte / échéances** : rassurer trésorerie et commande matériaux. Voir [acomptes et échéances](https://www.quotebuilder.co/blog/acomptes-echeances-devis-b2b).

Sans ça, vous bloquez des semaines d'équipe pour des prospects qui comparent encore chez trois couvreurs.

## Espace prospect et multi-décideurs

Après envoi, le prospect doit pouvoir :

- relire le récap (type d'intervention, surface / pans indicatifs, options, total) ;
- poser une question dans le fil de messages, sans relancer un e-mail perdu ;
- déposer une photo complémentaire ou un document syndic / assurance ;
- inviter un relecteur (directeur financier, responsable technique, acheteur ou décideur) sur le même lien.

C'est le rôle de l'[espace prospect](https://www.quotebuilder.co/blog/espace-prospect-devis-en-ligne). Sur syndic ou compte pro, le circuit de relecture est décrit dans [approbation client multi-décideurs](https://www.quotebuilder.co/blog/approbation-client-multi-decideurs-devis-b2b) : pastilles En attente / Consulté / Validé / Modifications, un commentaire et un budget max par personne. Le commercial pose ensuite le statut du devis.

## Relances : le devis toiture meurt souvent après l'envoi

Le prospect compare. Il attend un vote syndic. Il doit valider avec conjoint / assureur / direction. Sans relance, le dossier refroidit pendant que votre planning se remplit d'autres « peut-être ».

Cadrez une séquence courte :

- T+0 : confirmation + lien espace prospect ;
- T+1 j (urgence) ou T+2 j (projet) : rappel options (accès / zinguerie) + créneau visite si besoin ;
- T+5 j : rappel validité + prochain créneau chantier indicatif.

Adaptez selon le score Hot / Warm / Cold. Méthode générale : [pourquoi les devis meurent sans relance](https://www.quotebuilder.co/blog/pourquoi-les-devis-meurent-sans-relance) et [relancer un devis Hot](https://www.quotebuilder.co/blog/relancer-devis-hot-depuis-dossier).

## Erreurs fréquentes à éviter

1. **Promettre un prix au m² figé sans brief** : vous attirez des tireurs de prix.
2. **Inventer aides / CEE / primes dans le wizard** : litige assuré.
3. **Ignorer l'accès et la hauteur** : le coût sort au chantier.
4. **Traiter une fuite comme un projet long** (SLA trop lent) : le prospect appelle le voisin.
5. **Un seul PDF sans suivi** : relances à l'aveugle. Préférez le [lien sécurisé](https://www.quotebuilder.co/blog/envoyer-devis-lien-securise-vs-pdf-email).
6. **Réserver un créneau équipe avant que le dossier soit gagné** : vous bloquez pour un comparateur.
7. **Mélanger particulier, pro et syndic sur les mêmes champs** : branche « type de client » dès le début.
8. **Envoyer sans validation technique** sur un Hot complexe : le devis revient à la charge. Voir [validation interne](https://www.quotebuilder.co/blog/validation-interne-avant-envoi-devis-b2b).

## FAQ

### Peut-on chiffrer une réfection de toiture sans visite ?

Souvent un **indicatif** oui, si type d'intervention, surface ou pans, photos et accès sont corrects. Un devis ferme dépend de votre politique risque (charpente, sous-toiture, points singuliers, mitoyenneté).

### Faut-il afficher un prix au m² sur le site ?

Dangereux sans brief. Préférez un parcours qui aboutit à une estimation personnalisée, ou une fourchette très large clairement non contractuelle. Pas de barème « officiel » inventé.

### Comment gérer urgence fuite et projet long dans le même funnel ?

Branche précoce « contexte ». SLA et scoring différents. Même dossier ensuite.

### Comment parler des aides ou de l'assurance sans se tromper ?

Mention générique + collecte d'infos + traitement humain. Pas de barème inventé (CEE, primes, MaPrimeRénov' ou autre) dans le wizard. Pas de promesse de prise en charge assurance.

### Tuiles et étanchéité terrasse doivent-elles être deux funnels séparés ?

Pas forcément. Une branche « type d'intervention » dans le même funnel suffit souvent. Séparez seulement si les équipes / catalogues sont vraiment distincts.

### Comment éviter l'abandon à l'étape photos ?

Rendez l'upload optionnel mais valorisé (« avec photos toiture / accès, réponse plus rapide »). Proposez « je n'ai pas de photo » pour ne pas bloquer. Voir [pièces jointes / plans / photos](https://www.quotebuilder.co/blog/pieces-jointes-plans-photos-devis-b2b).

### Quel lien avec le catalogue produits ?

Les gammes couverture / zinguerie / forfaits pose du funnel doivent mapper vos kits / articles. Sinon double saisie. Voir bibliothèque de lignes / kits.

### Combien d'étapes idéales ?

Souvent 8 à 11. Au-delà, découpez (cœur puis technique) ou repoussez le détail après le score Hot.

### Comment démarrer sans refondre tout le site ?

Un widget funnel sur la page « Devis couverture / toiture » + catalogue minimal (2-3 familles, forfaits pose, options accès / zinguerie) suffit pour un pilote.

### Faut-il une validation interne avant d'envoyer un devis toiture complexe ?

Sur les Hot / paniers élevés / accès complexes, oui. Ça réduit les devis à reprendre et les remises de panique. Voir [validation interne avant envoi](https://www.quotebuilder.co/blog/validation-interne-avant-envoi-devis-b2b) et l'[estimateur coût devis sans validation](https://www.quotebuilder.co/outils/estimateur-cout-devis-sans-validation).

# Funnel de devis photovoltaïque et solaire : toiture, kWc, brief, signature

Un particulier, un syndic ou un responsable de site ouvre votre page. Il veut des panneaux solaires, parfois une batterie, parfois juste « un prix au kWc ». Il clique sur **Demander un devis**.

Puis il écrit : « Bonjour, tarif pour du photovoltaïque sur une maison. »

Pas de surface de toiture. Pas d’orientation. Pas de conso annuelle. Pas de type de client (particulier, pro, syndic). Pas d’accès toiture. Pas de photos. Votre technico rappelle. On reconstruit le brief. Parfois on se déplace pour découvrir une ombre portée, une tuile fragile ou un tableau électrique saturé. Parfois le prospect a déjà signé chez quelqu’un qui avait posé les bonnes questions dès le premier écran.

## Définition : devis photovoltaïque / solaire (ce qu’il doit contenir)

Un **devis photovoltaïque** est une proposition chiffrée pour une installation de production d’électricité solaire (et éventuellement de stockage) tenant compte au minimum de :

- le **type de projet** (résidentiel, tertiaire, syndic / copropriété, ombrière, hangar) ;
- la **toiture** ou support (tuile, bac acier, terrasse, sol) et une surface ou un nombre de modules indicatif ;
- une **puissance** d’ordre de grandeur (kWc) ou un objectif (autoconsommation, injection, mixte) ;
- l’**orientation / inclinaison** et les ombres éventuelles (même qualitatives au départ) ;
- la **consommation** annuelle ou un profil (facture, compteur, usage pro) ;
- l’**accès toiture** et les contraintes chantier (échafaudage, hauteur, sécurité) ;
- le **tableau / raccordement** (place disjoncteur, renforcement éventuel à confirmer en visite) ;
- l’option **stockage batterie** (oui / non / à étudier) ;
- le **délai de pose** et le mode d’intervention ;
- une **mention générique des aides ou dispositifs** éventuellement applicables (sans inventer de barème ni promettre un montant).

Sans toiture, orientation et conso (même approximatives), vous n’avez pas un devis : vous avez une fourchette marketing.

## Pourquoi le formulaire contact casse ce secteur

Le solaire cumule technique, planning chantier et attentes « aides / rentabilité ». Un textarea « message » produit :

- des leads hors zone ou hors compétence (toiture complexe, hauteur, amiante, etc.) ;
- des demandes « prix au kWc » impossibles à tenir sans brief ;
- des allers-retours sur les aides (le prospect veut un chiffre garanti, vous ne pouvez pas le coller dans un wizard public) ;
- des déplacements techniques inutiles faute de photos toiture / accès.

## Questions à poser dans le funnel (sans noyer le prospect)

Trop de questions tue la conversion. Trop peu tue le chiffrage. Compromis fréquent pour un installateur / réseau :

### Étape cœur (obligatoire)

1. Type de client : particulier, entreprise, syndic / copropriété, autre.
2. Type de besoin : production seule, production + batterie, « je ne sais pas / conseil ».
3. Support : toiture (tuile / bac / terrasse), sol, ombrière, hangar.
4. Surface toiture approximative **ou** objectif de puissance (kWc) / « je ne sais pas ».
5. Orientation approximative (sud, sud-est, etc.) et ombre éventuelle (arbres, voisin).
6. Consommation annuelle approximative ou « j’ai ma facture / je l’ajoute plus tard ».
7. Code postal (zone d’intervention).
8. Délai souhaité (urgent / saison / projet distant).
9. Photos toiture / accès ou « je n’ai pas encore de photo ».

### Étape technique (secondaire, ou après score Hot)

- Accès toiture (échelle, échafaudage, nacelle, hauteur).
- Âge / état de la couverture (qualitatif).
- Place au tableau électrique.
- Objectif : autoconsommation, revente / injection, mixte (selon votre offre).
- Batterie : capacité souhaitée ou « à dimensionner ».

### Étape contact

Identité, téléphone, créneau de rappel. Pour du B2B / syndic : SIRET, site, contact technique, éventuel conseil syndical.

Les options non choisies restent proposables plus tard en [variante](https://www.quotebuilder.co/blog/options-variantes-alternatives-devis-b2b), sans réécrire tout le devis.

## Aides et financements : ce qu’il faut dire (et ne pas inventer)

Les prospects demandent souvent : « Combien je touche d’aides ? » ou « Quelle rentabilité exacte ? »

Dans un funnel public, la posture saine est :

- **mentionner** que des dispositifs ou aides peuvent exister selon profil, type d’installation et réglementation en vigueur ;
- **ne pas afficher** de barèmes inventés ni de montants « garantis » ;
- **collecter** les infos utiles pour qu’un conseiller traite le dossier (statut occupant, type de bâtiment, etc., dans un parcours conforme) ;
- **clarifier** que le devis matériel / pose est distinct du montage d’aides ou de simulations financières détaillées.

Promettre un montant d’aide ou un taux de rentabilité figé dans un wizard marketing crée des litiges. Mieux vaut un champ « je souhaite être accompagné sur les aides / le financement (oui / non / je ne sais pas) » et un process humain derrière.

## Photos, accès toiture et visite

Le funnel ne remplace pas toujours la visite. Il **filtre** :

- dossiers incomplets ou hors zone → Cold / nurturing ;
- dossiers Hot avec photos exploitables → chiffrage indicatif puis visite courte ;
- dossiers complexes (copropriété, toiture fragile, ombre forte, tableau saturé, hauteur) → visite / étude avant devis ferme.

Clarifiez dans le parcours : « devis indicatif sous réserve de visite / étude » vs « devis ferme ». Ça évite les litiges sur la puissance réelle, le nombre de modules ou le coût d’accès.

## Options fréquentes à proposer (sans 15 écrans)

Regroupez plutôt que de multiplier les étapes :

- stockage batterie (plusieurs capacités ou « à dimensionner ») ;
- monitoring / application de suivi ;
- optimisation / boîtier associé (si vous le vendez) ;
- renfort structure / supports spécifiques (souvent après visite) ;
- dépose / reprise couverture localisée (si dans votre offre) ;
- contrat entretien / SAV (si vous le vendez).

Affichez-les comme options cochables. Le total bouge. Le prospect comprend. Vous évitez le « surprise chantier ».

## Délai de pose, validité et acomptes

Trois leviers à lier :

1. **Validité du devis** (ex. 30 jours) : matériel et planning bougent. Voir [validité / expiration](https://www.quotebuilder.co/blog/validite-expiration-devis-b2b).
2. **Créneau pose** : réservé après signature + acompte, pas sur un devis « peut-être ».
3. **Acompte / échéances** : rassurer trésorerie et commande matériel. Voir [acomptes et échéances](https://www.quotebuilder.co/blog/acomptes-echeances-devis-b2b).

Sans ça, vous bloquez des semaines de planning pour des prospects qui comparent encore chez trois installateurs.

## Espace prospect et signature

Après envoi, le prospect doit pouvoir :

- relire le récap (puissance indicative, options, total) ;
- poser une question sans relancer un e-mail perdu ;
- déposer une facture d’énergie, une photo toiture ou un plan complémentaire ;
- accepter / signer quand c’est le bon moment.

C’est le rôle de l’[espace prospect](https://www.quotebuilder.co/blog/espace-prospect-devis-en-ligne) et de la [signature / acceptation en ligne](https://www.quotebuilder.co/blog/signature-acceptation-devis-en-ligne-b2b). Moins de « vous avez bien reçu mon devis ? ».

## Relances : le devis PV meurt souvent après l’envoi

Le prospect compare. Il attend un devis concurrent. Il doit valider avec conjoint / syndic / direction. Sans relance, le dossier refroidit pendant que votre planning se remplit d’autres « peut-être ».

Cadrez une séquence courte :

- T+0 : confirmation + lien espace prospect ;
- T+2 j : rappel options (batterie / monitoring) + délai pose restant ;
- T+5 j : rappel validité + proposition créneau visite si besoin.

Adaptez selon le score Hot / Warm / Cold. Méthode générale : [pourquoi les devis meurent sans relance](https://www.quotebuilder.co/blog/pourquoi-les-devis-meurent-sans-relance) et [relancer un devis Hot](https://www.quotebuilder.co/blog/relancer-devis-hot-depuis-dossier).

## Erreurs fréquentes à éviter

1. **Promettre un montant d’aide ou une rentabilité figée dans le funnel** : litige assuré.
2. **Prix au kWc affiché sans brief** : vous attirez des tireurs de prix.
3. **Ignorer l’accès toiture et la hauteur** : le coût sort au chantier.
4. **Un seul PDF sans suivi** : relances à l’aveugle. Préférez le [lien sécurisé](https://www.quotebuilder.co/blog/envoyer-devis-lien-securise-vs-pdf-email).
5. **Réserver un créneau pose avant signature** : vous bloquez l’équipe pour un comparateur.
6. **Mélanger particulier, pro et syndic sur les mêmes champs** : branche « type de client » dès le début.

## FAQ

### Peut-on chiffrer une installation PV sans visite ?

Souvent un **indicatif** oui, si toiture, orientation, photos et conso (même approximative) sont corrects. Un devis ferme dépend de votre politique risque (structure, ombre, tableau, accès).

### Faut-il afficher un prix au kWc sur le site ?

Dangereux sans brief. Préférez un parcours qui aboutit à une estimation personnalisée, ou une fourchette très large clairement non contractuelle.

### Comment gérer particulier, pro et syndic dans le même funnel ?

Branche précoce « type de client », puis champs spécifiques (SIRET, lots, contact technique). Ne mélangez pas tout sur le même écran.

### Comment parler des aides sans se tromper ?

Mention générique + collecte d’infos + traitement humain. Pas de barème inventé dans le wizard.

### La batterie doit-elle être obligatoire dans le parcours ?

Non. Proposez-la en option ou en branche « je veux étudier le stockage ». Beaucoup de prospects veulent d’abord la production.

### Comment éviter l’abandon à l’étape photos ?

Rendez l’upload optionnel mais valorisé (« avec photos toiture, réponse sous 48 h »). Proposez « je n’ai pas de photo » pour ne pas bloquer. Voir aussi [pièces jointes / plans / photos](https://www.quotebuilder.co/blog/pieces-jointes-plans-photos-devis-b2b).

### Quel lien avec le catalogue produits ?

Les gammes modules / onduleurs / forfaits pose du funnel doivent mapper vos kits / articles. Sinon double saisie. Voir bibliothèque de lignes / kits.

### Combien d’étapes idéales ?

Souvent 8 à 11. Au-delà, découpez (cœur puis technique) ou repoussez le détail après le score Hot.

### Comment démarrer sans refondre tout le site ?

Un widget funnel sur la page « Devis solaire / PV » + catalogue minimal (2–3 gammes, forfaits pose, option batterie) suffit pour un pilote.

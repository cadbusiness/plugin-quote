# Pièces jointes, plans et photos dans un devis B2B : du chaos WhatsApp au brief chiffrable

Jeudi 11 h 20. Un prospect envoie trois photos floues sur WhatsApp. Le commercial répond « ok je regarde ». L’après-midi, un plan PDF arrive dans un autre fil mail, sans numéro de version. Le lundi suivant, le bureau d’études ouvre encore `plan_v2_final.pdf` alors que le client a déjà envoyé `plan_v3` sur Teams. Personne n’a le même brief. Le devis sort avec une cote fausse. Le chantier commence mal, ou le deal meurt dans la clarification.

## Ce que « pièce jointe » veut dire dans un devis B2B

Dans le langage courant, une pièce jointe est un fichier collé à un mail. Dans un process devis, c’est autre chose : c’est une **preuve de brief**.

Un devis chiffrable repose souvent sur :

- des **photos** du site (accès, état existant, contraintes) ;
- un **plan** (DWG, PDF, croquis coté) ;
- une **spec** ou un cahier des charges ;
- parfois un PDF technique fournisseur, une note de calcul, un export BIM simplifié.

Si ces fichiers vivent dans quatre canaux (WhatsApp, mail perso, Drive perso, SMS), le devis n’a plus de source de vérité. Vous ne chiffrez pas un projet. Vous chiffrez une conversation fragmentée.

Le contraste avec [qualifier une demande avant chiffrage](https://www.quotebuilder.co/blog/qualifier-demande-devis-avant-chiffrage) est direct : sans documents exploitables, le score Hot n’a pas de sens. Vous avez un lead chaud sur le papier et un dossier froid côté technique.

## Pourquoi WhatsApp et les mails orphelins coûtent cher

WhatsApp n’est pas « interdit ». Il est **mauvais comme dossier**.

### Ce qui fuit tout de suite

1. **Pas de dossier unique** : le fil est lié à un téléphone, pas à une opportunité pipeline.
2. **Compression d’image** : les cotes deviennent illisibles, les plans trop lourds refusés, les photos floues.
3. **Hors équipe** : le commercial part en congés, le technico ne voit pas le fil.
4. **Pas de version** : « la dernière photo » n’est jamais définie.
5. **Hors conformité / hors archive** : quand le litige arrive, le fil a disparu ou a été archivé ailleurs.

Le mail n’est guère mieux quand chaque message crée un nouveau fil « RE: RE: plan ». Les pièces trop lourdes bloquent. Les proxies entreprise mangent les PDF. Deux décideurs forwardent deux versions différentes. Voir aussi le coût du [PDF en e-mail vs lien sécurisé](https://www.quotebuilder.co/blog/envoyer-devis-lien-securise-vs-pdf-email).

### Le coût réel (pas le coût du stockage)

Le stockage cloud est presque gratuit. Ce que vous payez :

- minutes de rappel (« tu peux renvoyer le plan ? ») ;
- minutes de recherche dans les boîtes ;
- déplacements inutiles parce que la photo d’accès n’existait pas ;
- devis faux puis refaits ;
- opportunités perdues pendant que vous reconstruisez le brief.

## Anatomie d’un brief chiffrable (documents inclus)

Un brief chiffrable n’est pas un roman. C’est un **paquet minimum** :

| Élément | Rôle | Sans lui |
|---------|------|----------|
| Type de besoin + contraintes | Cadre le chiffrage | Fourchette marketing |
| Dimensions / puissance / quantité | Base de calcul | Estimation au doigt mouillé |
| Photos site / existant | Accès, état, surprises | Déplacement « pour voir » |
| Plan ou croquis coté | Géométrie | Erreur de cote |
| Spec / PDF technique | Produit exact | Variante non voulue |
| Contact + délai | Priorisation | Dossier perdu |

Vous n’avez pas toujours tout le jour J. L’important est de **savoir ce qui manque** et de le demander au même endroit, pas dans trois apps.

Le funnel (wizard) peut déjà filtrer : « j’ai un plan », « j’ai des photos », « je n’ai rien encore ». L’[espace prospect](https://www.quotebuilder.co/blog/espace-prospect-devis-en-ligne) complète ensuite : le prospect dépose ce qu’il a quand il l’a.

## Process métier : où placer les documents

Voici un process simple, transposable menuiserie, rayonnage, PAC, solaire, clôture.

### 1. Entrée (funnel ou formulaire structuré)

Dès la demande :

- type de projet ;
- zone / code postal ;
- délai ;
- case « je joins un plan / des photos » (upload optionnel mais valorisé) ;
- case « je n’ai pas encore de document ».

Ne bloquez pas la conversion sur un upload obligatoire si le prospect est dans le train. Proposez plutôt : « avec photos, réponse sous 48 h ; sans photos, on vous rappelle pour cadrer. »

### 2. Dossier unique (pipeline)

Chaque demande ouvre un dossier avec un ID. Les fichiers uploadés y arrivent. Pas dans la boîte perso du commercial. C’est le même principe que [centraliser les demandes multi-canaux](https://www.quotebuilder.co/blog/centraliser-demandes-devis-multi-canaux).

### 3. Qualification

Score Hot / Warm / Cold en regardant aussi la qualité documentaire. Un Hot sans photo d’accès sur un chantier contraint n’est peut-être qu’un Warm. Voir [qualifier avant chiffrage](https://www.quotebuilder.co/blog/qualifier-demande-devis-avant-chiffrage) et [score demande](https://www.quotebuilder.co/blog/score-demande-devis-b2b).

### 4. Chiffrage

L’estimateur travaille sur le dossier, pas sur un forward WhatsApp. Les lignes catalogue / kits restent stables. Voir [bibliothèque de lignes et kits](https://www.quotebuilder.co/blog/bibliotheque-lignes-kits-devis-b2b).

### 5. Envoi + espace prospect

Le prospect reçoit un **lien** (idéalement sécurisé). Il voit le devis, dépose un plan manquant, commente. Vous évitez le « je vous renvoie le PDF + le plan dans un autre mail ». Lien vs PDF : [envoyer devis lien sécurisé](https://www.quotebuilder.co/blog/envoyer-devis-lien-securise-vs-pdf-email).

### 6. Versions

Quand le plan change, vous créez une **version de devis** liée au nouveau document, pas un `v3_final_vraiment.pdf` perdu. Voir [versions et historique](https://www.quotebuilder.co/blog/versions-historique-devis-b2b).

## Formats, taille, nommage : règles pragmatiques

Vous n’avez pas besoin d’une norme ISO en PME. Vous avez besoin de **règles tenables**.

### Formats acceptés (exemple)

- Photos : JPG / PNG / HEIC (si votre stack le convertit).
- Plans : PDF, parfois DWG (si votre équipe lit le DWG ; sinon exporter PDF coté).
- Specs : PDF, DOCX.
- Éviter les archives ZIP opaques sans légende.

### Taille

Fixez un plafond clair (ex. 20 Mo par fichier) et un message humain si ça casse. Proposez de compresser ou de découper. Mieux vaut deux PDF lisibles qu’un 180 Mo qui n’arrive jamais.

### Nommage côté équipe

À l’upload, préférez un libellé métier dans le dossier :

- `plan_implantation_client` ;
- `photo_acces_camion` ;
- `spec_fournisseur_gamme_X`.

Le nom fichier original du client peut rester en métadonnée. Ce qui compte, c’est que l’équipe retrouve le rôle du document en deux secondes.

### Légendes

Une photo sans légende (« façade nord, accès étroit ») vaut moins. Dans l’espace prospect, un champ commentaire à côté de l’upload change la qualité du brief.

## Versions de plans et versions de devis (ne pas confondre)

Deux historiques distincts :

1. **Version document** : plan v1, v2, v3. La v3 remplace la v2 pour le chiffrage.
2. **Version devis** : proposition commerciale v1 (sur plan v2), puis devis v2 (sur plan v3 + option B).

Si vous mélangez les deux dans un seul nom de fichier (`Devis_Martin_planv3_FINAL.pdf`), personne ne sait ce qui a bougé : le prix, l’option, ou la géométrie.

Bon réflexe logiciel :

- le dossier liste les documents avec date et auteur ;
- le devis pointe vers « plan courant » ;
- chaque envoi commercial est une version traçable ;
- l’acceptation / signature se fait sur la **version courante**, pas sur un PDF forwardé. Voir [signature et acceptation](https://www.quotebuilder.co/blog/signature-acceptation-devis-en-ligne-b2b).

## Rôle de l’espace prospect pour les pièces jointes

L’[espace prospect](https://www.quotebuilder.co/blog/espace-prospect-devis-en-ligne) n’est pas un gadget « joli lien ». C’est le **tiroir partagé** :

- le prospect dépose photos et plans sans créer un nouveau canal ;
- plusieurs décideurs voient les mêmes fichiers ;
- vous voyez quand un document arrive (et vous relancez autrement qu’avec « avez-vous reçu mon mail ? ») ;
- le commercial et le technico travaillent sur la même base.

Sans espace prospect, même un bon funnel initial se dégrade : après le premier devis, tout repart en WhatsApp.

## Erreurs fréquentes

1. **Upload obligatoire trop tôt** : vous tuez la conversion. Mieux vaut optionnel + SLA différencié.
2. **Accepter WhatsApp comme archive** : le fil disparaît, l’équipe aussi.
3. **Un seul PDF fourre-tout** : plan + devis + CGV dans le même fichier, impossible à versionner.
4. **Pas de légende** : photo jolie, inutilisable.
5. **Chiffrer sur un plan « peut-être à jour »** : validez la version courante avant de sortir le prix.
6. **Relancer sans regarder les uploads** : le prospect a déjà déposé le plan ; votre mail « merci de renvoyer » casse la confiance.

## Logiciel devis : ce que ça change concrètement

Un bon outil ne « stocke pas des fichiers ». Il **attache** les fichiers au cycle :

- funnel → dossier ;
- dossier → chiffrage ;
- chiffrage → lien prospect ;
- prospect → nouveaux uploads ;
- nouvelle version → relance / signature.

C’est la même logique que le [configurateur vs Excel + PDF](https://www.quotebuilder.co/blog/configurateur-devis-vs-excel-pdf) : Excel peut calculer. Il ne porte pas le brief vivant.

QuoteBuilder (et des outils du même type) vise ce fil : demande structurée, documents dans le dossier, espace prospect, versions. Pas magique. Juste moins de friction.

## FAQ

### Faut-il interdire WhatsApp pour les devis ?

Non. Interdisez-en le rôle d’**archive**. Un prospect peut vous alerter sur WhatsApp ; le document utile doit atterrir dans le dossier / espace prospect.

### Que faire si le plan est un DWG et que le commercial ne l’ouvre pas ?

Demandez un PDF coté en parallèle, ou une revue courte par le bureau d’études avant chiffrage. Le funnel peut proposer « PDF plan » comme format préféré.

### Comment gérer les photos trop compressées ?

Expliquez dans l’espace prospect : « idéalement sans compression agressive, une photo par angle ». Proposez un second upload si illisible. Mieux que de chiffrer à l’aveugle.

### Combien de documents maximum par dossier ?

Assez pour chiffrer, pas une bibliothèque. Souvent 3 à 10 fichiers utiles. Au-delà, demandez un index (quoi est quoi) ou un plan « courant » clairement marqué.

### Le prospect peut-il remplacer un plan déjà uploadé ?

Oui, et ça doit créer une **nouvelle version document** visible, pas écraser en silence sans que l’estimateur le sache.

### Quel lien avec la validité du devis ?

Si le plan change après envoi, la proposition peut être caduque. Affichez la validité et, si besoin, renvoyez une version. Voir [validité / expiration](https://www.quotebuilder.co/blog/validite-expiration-devis-b2b).

### Comment prioriser les dossiers sans photos ?

SLA plus long, ou étape « cadrage express » avant chiffrage. Ne brûlez pas l’équipe estimateur sur des briefs vides.

### Peut-on démarrer sans espace prospect ?

Oui, avec un Drive partagé par dossier. Vous gagnerez déjà face à WhatsApp. L’espace prospect ajoute le lien devis + statut + multi-décideurs + moins de forward.

# Funnel de devis électricité tertiaire : dépannage, mise en conformité, neuf, brief scoré

Un responsable de site, un syndic ou un gérant de commerce ouvre votre page. Panne partielle, tableau saturé, mise en conformité, neuf sur chantier, éclairage à reprendre. Il clique sur **Demander un devis**.

Puis il écrit : « Bonjour, tarif électricité. »

Pas de type d'intervention. Pas de type de site (bureau, commerce, entrepôt, parties communes). Pas d'idée de puissance ou d'accès. Pas de photos du tableau ou des locaux. Pas d'urgence réelle vs projet distant. Pas de distinction pro / syndic / bailleur. Votre chargé d'affaires rappelle. On reconstruit le brief. Parfois on se déplace pour découvrir un local fermé, un projet non voté, ou un devis déjà pris ailleurs. Parfois le prospect a déjà choisi quelqu'un qui avait posé les bonnes questions dès le premier écran.

Ce n'est pas seulement un sujet commercial. C'est un sujet d'**entrée**.

Cette page explique comment un **funnel de devis électricité tertiaire** transforme une demande vague en **brief chiffrable** : type d'intervention, type de site, contraintes d'accès / puissance perçue, photos, urgence, type de client, options / variantes, puis dossier scoré, espace prospect et statut commercial clair (dont **Gagné** posé par vous). Public : entreprises d'électricité tertiaire et pro, artisans électriciens qui travaillent bureaux / commerces / entrepôts, réseaux multi-agences, bureaux qui outillent ces équipes.

## Définition : devis électricité tertiaire (ce qu'il doit contenir)

Un **devis électricité** en tertiaire / pro (dépannage, conformité, rénovation, neuf, éclairage) est une proposition chiffrée tenant compte au minimum de :

- le **type d'intervention** (dépannage / panne, mise en conformité, rénovation de tableau, neuf / chantier, éclairage, courants faibles / VDI léger, « je ne sais pas / conseil ») ;
- le **type de site** (bureau, commerce, entrepôt / logistique, parties communes, local technique, autre) ;
- l'**accès** (horaires d'ouverture, local fermé, hauteur, intervention hors heures, contraintes syndic) ;
- une **idée de contrainte puissance / existant** (tableau saturé, extension, création de points, « je ne sais pas ») sans exiger un dimensionnement officiel dans le wizard public ;
- les **photos** (tableau, locaux, zones à éclairer, cheminements visibles) ;
- le **contexte** : urgence vs projet planifié ;
- le **type de client** (entreprise / pro, syndic / copropriété, bailleur, particulier en secondaire) ;
- les **options** (dépose, mise en sécurité, éclairage de secours, chemins de câbles, reprises après travaux, interventions de nuit…) ;
- une **mention générique** si le prospect parle de NF C 15-100, Consuel ou habilitation : contexte métier courant, **pas** un module QuoteBuilder ni un « certificat officiel » généré par le logiciel.

Sans type d'intervention, type de site et un minimum d'accès / photos, vous n'avez pas un devis : vous avez une fourchette marketing.

## Pourquoi le formulaire contact casse ce secteur

L'électricité tertiaire cumule urgence (panne), technique (tableau, puissance, cheminements), accès site et parfois multi-décideurs (exploitant, syndic, Achats, bureau de contrôle). Un textarea « message » produit :

- des leads hors zone ou hors compétence (industrielle lourde, haute tension, etc.) ;
- des demandes « prix mise aux normes » impossibles sans brief ;
- des [visites techniques inutiles](https://www.quotebuilder.co/blog/visite-technique-avant-devis-b2b) faute de photos / accès ;
- des dossiers « urgence » traités comme des projets longs (ou l'inverse) ;
- des allers-retours sur la conformité (le prospect veut une garantie magique dans un wizard ; vous devez rester prudents).

Le contraste [formulaire contact vs funnel devis B2B](https://www.quotebuilder.co/blog/formulaire-contact-vs-funnel-devis-b2b) s'applique ici avec une friction forte. Les [pièces jointes, plans et photos](https://www.quotebuilder.co/blog/pieces-jointes-plans-photos-devis-b2b) ne sont pas un détail ; elles sont souvent le brief. Pour qualifier avant chiffrage : [qualifier une demande](https://www.quotebuilder.co/blog/qualifier-demande-devis-avant-chiffrage). ## Questions à poser dans le funnel (sans noyer le prospect)

Trop de questions tue la conversion. Trop peu tue le chiffrage. Compromis fréquent pour une entreprise d'électricité tertiaire :

### Étape cœur (obligatoire)

1. Type de client : entreprise / pro, syndic / copropriété, bailleur, particulier / autre.
2. Contexte : dépannage / panne, mise en conformité, rénovation tableau, neuf / chantier, éclairage, courants faibles / VDI léger, « je ne sais pas / conseil ».
3. Type de site : bureau, commerce, entrepôt, parties communes, local technique, autre.
4. Accès : horaires d'ouverture, intervention possible en journée / hors heures, local fermé, hauteur, « je ne sais pas ».
5. Code postal (zone d'intervention ; triage équipe).
6. Délai souhaité (urgent / sous 48 h / sous 2 semaines / projet distant / vote syndic).
7. Photos du tableau / des locaux / de la zone, ou « je n'ai pas encore de photo ».

### Questions techniques (dans le même ordre fixe)

Elles viennent après les questions cœur, toujours dans le même ordre. Le score Hot, Warm ou Cold n'est calculé qu'à la soumission. L'équipe trie les dossiers ensuite.

- Nature du problème (coupure partielle, disjoncteur, prises / éclairage HS, extension, création points, remodelage…).
- Contrainte existant / puissance perçue (tableau saturé, agrandissement, neuf, « à étudier sur place »).
- Surface approximative ou nombre de locaux concernés (si éclairage / neuf léger).
- Courants faibles / VDI léger : oui / non / à conseiller (sans inventer un catalogue complet dans le wizard).
- Présence d'un décideur / accès badges le jour d'une éventuelle visite : oui / non / à confirmer.
- Mention générique conformité (NF C 15-100 / Consuel / contrôles) : le prospect en parle ? oui / non / je ne sais pas (collecte, pas de montage réglementaire automatique).

### Étape contact

Identité, téléphone, créneau de rappel. Pour du B2B / syndic : SIRET si utile, site, contact technique, éventuel bureau de contrôle / AMO.

Les options non choisies restent proposables plus tard en [variante](https://www.quotebuilder.co/blog/options-variantes-alternatives-devis-b2b), sans réécrire tout le devis. Pas de « kits » magiques : options, variantes et produits liés suffisent.

## Dépannage vs conformité vs neuf : trois vitesses, un funnel

Ne créez pas trois sites. Créez une **branche précoce** « contexte » (dans le sens métier ; côté produit QuoteBuilder les étapes restent dans un ordre fixe, les If/Then orientent surtout les suggestions produits).

| Contexte | Brief minimal | Priorité typique |
|----------|---------------|------------------|
| Dépannage / panne | Site, symptômes, accès, photos si safe | SLA équipe court, score utile surtout si brief complet |
| Mise en conformité | Site, existant / photos tableau, horizon décision | Souvent Warm → Hot quand photos + décideur |
| Rénovation tableau | Photos, contraintes accès, usage du site | Visite fréquente si risque |
| Neuf / chantier | Plans, planning, lots, interlocuteur | Hot si budget / calendrier clairs |
| Éclairage | Locaux, usage, photos, contraintes hauteur | Indicatif possible avec bon brief |
| Courants faibles / VDI léger | Besoin (réseau, contrôle d'accès léger…), site | À cadrer tôt pour ne pas mélanger avec le fort |

L'urgence perçue guide le **triage équipe** (qui rappelle en premier). Sur QuoteBuilder, le score Hot / Warm / Cold reste une **formule fixe**, calculée à la soumission (surface, load, access, project_type, constraints, longueur du besoin) : elle ignore photos, zone, urgence et contexte. Elle n'est pas configurable. Pas de SLA produit : vos délais de réponse dépannage sont les vôtres.

## Photos tableau et locaux : le brief que le téléphone ne remplace pas

Un appel « le tableau est vieux » sans photo mène souvent à une visite pour collecter ce que le funnel devait collecter. Demandez au minimum :

- vue d'ensemble du tableau (porte ouverte si possible, sans geste dangereux demandé au prospect) ;
- zone concernée (local, open space, réserve, parties communes) ;
- contraintes d'accès visibles (hauteur, passage, faux-plafond) ;
- pour l'éclairage : photos des locaux dans l'usage réel si possible.

Rendez l'upload **valorisé** (« avec photos, réponse plus rapide ») mais pas bloquant : proposez « je n'ai pas de photo ». Voir [pièces jointes / plans / photos](https://www.quotebuilder.co/blog/pieces-jointes-plans-photos-devis-b2b) et, si l'entrée est orale, [téléphone / WhatsApp vers brief](https://www.quotebuilder.co/blog/telephone-whatsapp-vers-brief-devis-b2b).

## NF C 15-100, Consuel, habilitation : contexte métier, pas feature produit

Les prospects parlent souvent de « normes », de Consuel ou d'habilitation. Traitez-le comme du **vocabulaire métier** :

- vous pouvez collecter « le prospect mentionne une mise en conformité / un passage Consuel » ;
- vous ne devez pas présenter QuoteBuilder comme un outil qui « délivre » la conformité, calcule une norme officielle ou remplace un bureau de contrôle ;
- le chiffrage reste le vôtre (fourchette indicative min–max en euros entiers côté produit ; pas de TVA stockée comme feature devis dans QuoteBuilder).

Restez sobres dans les pages marketing et dans le wizard.

## Parcours type : du clic au statut Gagné

1. **Entrée** : funnel site, widget, lien préfill, ou capture orale : le commercial remplit le funnel via le lien préfill ([préremplir via URL](https://www.quotebuilder.co/blog/preremplir-devis-url-parametres)).
2. **Brief** : type d'intervention, site, accès, photos si possible, besoin rédigé.
3. **Score + owner** : étiquette Hot / Warm / Cold calculée à la soumission (formule fixe) + triage urgence / zone par l'équipe. Voir [score demande](https://www.quotebuilder.co/blog/score-demande-devis-b2b) et [délai de réponse](https://www.quotebuilder.co/blog/delai-reponse-demande-devis-b2b).
4. **Décision visite** : Hot avec risque réel → visite courte ; Warm → photos / rappel ; Cold → pas de fourgon par défaut ([visite technique avant devis](https://www.quotebuilder.co/blog/visite-technique-avant-devis-b2b)). QuoteBuilder ne planifie pas les tournées.
5. **Chiffrage** : lignes catalogue, options / variantes, fourchette indicative.
6. **Envoi** : lien [espace prospect](https://www.quotebuilder.co/blog/espace-prospect-devis-en-ligne). Sur syndic / compte pro, invitez les relecteurs (Responsable technique, Directeur financier…). Ils peuvent **Valider le dossier** ou demander des **Modifications** (commentaire + budget max). Chat en fil plat. Pas d'acceptation en ligne inventée : le commercial pose **Gagné**.
7. **Relances** adaptées au score et à l'urgence. Méthode : [relancer un devis Hot](https://www.quotebuilder.co/blog/relancer-devis-hot-depuis-dossier).
8. **Clôture** : **Gagné** ou **Perdu**. Statuts CRM uniquement : Commencée, Nouveau, Contacté, En cours, Gagné, Perdu, En attente.

## Catalogue et options (sans kits inventés)

Côté produit, travaillez avec **options, variantes et produits liés**, pas des « kits / bundles » magiques ni un CTA « Essayer le template électricité » (il n'existe pas de template secteur électricité dans QuoteBuilder). Exemples de lignes / options à préparer dans *votre* catalogue :

- dépannage / mise en sécurité ;
- rénovation tableau (à décliner selon votre réalité) ;
- points d'éclairage / reprises ;
- cheminements / goulottes (si vous les vendez) ;
- option intervention hors heures ;
- option reprise après corps d'état ;
- option courants faibles légers si vous les proposez.

Les prix restent les vôtres. Pas de barème national inventé sur la landing.

## Relances typiques (à adapter)

- T+0 (dépannage) : rappel ou créneau intervention ;
- T+0 / T+1 (projet) : envoi indicatif ou confirmation de visite ;
- T+2 j : rappel options (hors heures / reprises) ;
- T+5 j : relance Hot avec question précise ;
- puis nurturing ou **Perdu** assumé.

Adaptez selon Hot / Warm / Cold et votre triage urgence. Méthode générale : [pourquoi les devis meurent sans relance](https://www.quotebuilder.co/blog/pourquoi-les-devis-meurent-sans-relance).

## Erreurs fréquentes en électricité tertiaire

1. **Traiter toute demande comme une panne** (ou l'inverse) : question « contexte » dès le début, dans l'ordre fixe.
2. **Visiter sans photos** : vous payez pour collecter le brief.
3. **Promettre un forfait « mise aux normes » national** sans existant ni accès.
4. **Mélanger particulier, pro et syndic** sur les mêmes champs.
5. **Présenter NF C 15-100 / Consuel comme feature logicielle** : restez sur le contexte métier.
6. **Envoyer sans validation** sur un Hot complexe (accès, gros lot, multi-sites) : voir [validation interne](https://www.quotebuilder.co/blog/validation-interne-avant-envoi-devis-b2b).
7. **Promettre une acceptation en ligne inventée** : espace prospect + relecteurs aident ; le commercial pose **Gagné**.
8. **Un seul PDF forwardé** sur un syndic / Achats : préférez le lien et les invitations relecteurs ([approbation multi-décideurs](https://www.quotebuilder.co/blog/approbation-client-multi-decideurs-devis-b2b)).

## FAQ

### Peut-on chiffrer une rénovation de tableau sans visite ?

Souvent un **indicatif** oui, si type d'intervention, site, photos et accès sont corrects. Un devis ferme dépend de votre politique risque (existant, puissance, cheminements, surprises).

### Faut-il afficher un prix forfait dépannage sur le site ?

Dangereux sans brief. Préférez un parcours qui aboutit à une estimation personnalisée, ou une fourchette très large clairement non contractuelle. Pas de barème « officiel » inventé.

### Comment gérer dépannage et projet long dans le même funnel ?

Une question « contexte », posée dans un ordre fixe. Le score Hot, Warm ou Cold est calculé à la soumission. L'équipe trie ensuite. Même dossier ensuite. Les étapes produit restent en ordre fixe ; vos priorités d'équipe font le reste.

### Comment parler de NF C 15-100 ou Consuel sans se tromper ?

Mention générique + collecte d'infos + traitement humain. Pas de promesse de conformité automatique dans le wizard, et pas comme feature QuoteBuilder.

### Dépannage et éclairage doivent-ils être deux funnels ?

Pas forcément. Une question « type d'intervention », dans le même funnel et dans un ordre fixe, suffit souvent. Le score Hot, Warm ou Cold est calculé à la soumission. L'équipe trie ensuite. Séparez seulement si les équipes / catalogues sont vraiment distincts.

### Comment éviter l'abandon à l'étape photos ?

Rendez l'upload optionnel mais valorisé. Proposez « je n'ai pas de photo » pour ne pas bloquer. Voir [pièces jointes / plans / photos](https://www.quotebuilder.co/blog/pieces-jointes-plans-photos-devis-b2b).

### QuoteBuilder planifie-t-il les interventions électriciens ?

Non. Le produit aide à filtrer et scorer les demandes, chiffrer, partager l'espace prospect et relancer. L'agenda terrain reste hors produit. Ce n'est pas non plus un client WhatsApp.

### Combien d'étapes idéales ?

Souvent 8 à 11 questions, dans un ordre fixe. Le score Hot, Warm ou Cold est calculé à la soumission. L'équipe trie les dossiers ensuite.

### Comment démarrer sans refondre tout le site ?

Un widget funnel sur la page « Devis électricité » + catalogue minimal (dépannage, quelques lignes tableau / éclairage, options accès / hors heures) suffit pour un pilote. Pas de template secteur « électricité » à activer d'un clic dans le produit.

### Faut-il une validation interne avant d'envoyer un devis électricité complexe ?

Sur les Hot / paniers élevés / accès complexes / multi-sites, oui. Ça réduit les devis trop optimistes. Voir [validation interne avant envoi](https://www.quotebuilder.co/blog/validation-interne-avant-envoi-devis-b2b).

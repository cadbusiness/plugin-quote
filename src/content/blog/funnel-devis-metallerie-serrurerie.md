# Funnel de devis métallerie et serrurerie : portails, garde-corps, structures, brief scoré

Un syndic, un responsable de site ou un gérant de commerce ouvre votre page. Portail à remplacer, garde-corps à reprendre, escalier métal, grille, porte industrielle légère, blindage léger, dépannage serrurerie pro. Il clique sur **Demander un devis**.

Puis il écrit : « Bonjour, tarif métallerie. »

Pas de type d'intervention (neuf, remplacement, dépannage, reprise). Pas de type d'ouvrage. Pas de dimensions approximatives. Pas d'accès chantier. Pas de photos. Pas de distinction particulier / pro / syndic / collectivité. Votre chargé d'affaires rappelle. On reconstruit le brief. Parfois on se déplace pour découvrir un accès impossible, un ouvrage hors compétence, ou un devis déjà pris ailleurs. Parfois le prospect a déjà choisi quelqu'un qui avait posé les bonnes questions dès le premier écran.

Ce n'est pas seulement un sujet commercial. C'est un sujet d'**entrée**.

Cette page explique comment un **funnel de devis métallerie / serrurerie / ferronnerie** transforme une demande vague en **brief chiffrable** : type d'intervention, type d'ouvrage, dimensions approximatives, accès, photos, usage (particulier / pro / syndic / collectivité), options (pose, dépose, finition, galva / peinture, contrôle d'accès léger), puis dossier scoré, espace prospect et statut commercial clair (dont **Gagné** posé par vous). Public : métalliers, serruriers pro, ferronniers, entreprises multi-agences, bureaux qui outillent ces équipes.

## Définition : devis métallerie / serrurerie (ce qu'il doit contenir)

Un **devis métallerie** ou **serrurerie** (portail, garde-corps, escalier, grille, structure légère, dépannage) est une proposition chiffrée tenant compte au minimum de :

- le **type d'intervention** (neuf / fabrication, remplacement, reprise / réparation, dépannage serrurerie, pose seule, « je ne sais pas / conseil ») ;
- le **type d'ouvrage** (portail, clôture métallique, garde-corps, escalier / limon, porte industrielle légère, grille / barreaudage, structure / charpente légère, blindage léger, autre) ;
- les **dimensions approximatives** (largeur, hauteur, longueur de linéaire, nombre de marches…) sans exiger un relevé laser dans le wizard public ;
- l'**accès chantier** (étage, cour, grue, rue étroite, horaires syndic, site en activité) ;
- les **photos** (existant, ouverture, ancrages visibles, accès) ;
- le **contexte** : urgence vs projet planifié ;
- le **type de client** (particulier, pro / entreprise, syndic / copropriété, collectivité / bailleur) ;
- les **options** (pose, dépose, évacuation, finition, galvanisation / peinture, motorisation légère / contrôle d'accès léger si vous le proposez) ;
- une **mention générique** si le prospect parle de normes, ERP ou sécurité incendie : vocabulaire métier courant, **pas** un module QuoteBuilder qui « délivre » une conformité.

Sans type d'ouvrage, dimensions approximatives et un minimum d'accès / photos, vous n'avez pas un devis : vous avez une fourchette marketing.

## Pourquoi le formulaire contact casse ce secteur

La métallerie / serrurerie cumule fabrication (délais atelier), pose (accès, ancrages), urgence (panne, sécurisation) et parfois multi-décideurs (syndic, Achats, collectivité). Un textarea « message » produit :

- des leads hors compétence (structure lourde, ferronnerie d'art hors offre, industrielle hors rayon) ;
- des demandes « prix portail » impossibles sans largeur / hauteur / motorisation ;
- des [visites techniques inutiles](https://www.quotebuilder.co/blog/visite-technique-avant-devis-b2b) faute de photos / accès ;
- des dossiers « urgence » traités comme des projets longs (ou l'inverse) ;
- des allers-retours sur la finition (galva, thermolaquage, RAL) découverts trop tard.

Le contraste [formulaire contact vs funnel devis B2B](https://www.quotebuilder.co/blog/formulaire-contact-vs-funnel-devis-b2b) s'applique ici avec une friction forte. Les [pièces jointes, plans et photos](https://www.quotebuilder.co/blog/pieces-jointes-plans-photos-devis-b2b) ne sont pas un détail ; elles sont souvent le brief. Pour qualifier avant chiffrage : [qualifier une demande](https://www.quotebuilder.co/blog/qualifier-demande-devis-avant-chiffrage). Beaucoup d'entrées arrivent aussi à l'oral : voir [téléphone / WhatsApp vers brief](https://www.quotebuilder.co/blog/telephone-whatsapp-vers-brief-devis-b2b). Le handoff commercial → atelier / pose est critique : [transfert brief commercial → technique](https://www.quotebuilder.co/blog/transfert-brief-commercial-technique-devis-b2b).

## Questions à poser dans le funnel (sans noyer le prospect)

Trop de questions tue la conversion. Trop peu tue le chiffrage. Compromis fréquent pour une entreprise de métallerie / serrurerie :

### Étape cœur (obligatoire)

1. Type de client : particulier, entreprise / pro, syndic / copropriété, collectivité / bailleur / autre.
2. Contexte : neuf / fabrication, remplacement, reprise / réparation, dépannage serrurerie, pose seule, « je ne sais pas / conseil ».
3. Type d'ouvrage : portail, clôture, garde-corps, escalier métal, porte / accès, grille, structure légère, blindage léger, autre.
4. Dimensions approximatives : largeur / hauteur / linéaire / marches, ou « je ne sais pas encore ».
5. Accès chantier : plain-pied, étage, cour intérieure, contraintes rue / grue, horaires, « je ne sais pas ».
6. Code postal (zone d'intervention ; triage équipe).
7. Délai souhaité (urgent / sous 48 h / sous 2 semaines / projet distant / vote syndic).
8. Photos de l'existant / de l'ouverture / de l'accès, ou « je n'ai pas encore de photo ».

### Étape technique (secondaire, ou après score Hot)

- Usage / contraintes (passage véhicules, ERP, enfants, site en activité…).
- Finition souhaitée (brut, galva, peinture / thermolaquage, RAL connu / à conseiller).
- Pose / dépose / évacuation : oui / non / à étudier.
- Motorisation ou contrôle d'accès léger : oui / non / à conseiller (sans inventer un catalogue complet dans le wizard).
- Présence d'un décideur / accès badges le jour d'une éventuelle visite : oui / non / à confirmer.
- Mention générique normes / sécurité : le prospect en parle ? oui / non / je ne sais pas (collecte, pas de montage réglementaire automatique).

### Étape contact

Identité, téléphone, créneau de rappel. Pour du B2B / syndic / collectivité : SIRET si utile, site, contact technique, éventuel AMO / bureau de contrôle.

Les options non choisies restent proposables plus tard en [variante](https://www.quotebuilder.co/blog/options-variantes-alternatives-devis-b2b), sans réécrire tout le devis. Pas de « kits » magiques : options, variantes et produits liés suffisent.

## Dépannage vs fabrication vs pose : trois vitesses, un funnel

Ne créez pas trois sites. Créez une **branche précoce** « contexte » (dans le sens métier ; côté produit QuoteBuilder les étapes restent dans un ordre fixe, les If/Then orientent surtout les suggestions produits).

| Contexte | Brief minimal | Priorité typique |
|----------|---------------|------------------|
| Dépannage serrurerie | Site, symptômes, accès, sécurisation | SLA équipe court ; score utile si brief complet |
| Remplacement (portail, garde-corps…) | Dimensions approx, photos, accès, finition | Warm → Hot quand photos + décideur |
| Neuf / fabrication | Plans ou cotes, délai atelier, interlocuteur | Hot si calendrier / budget clairs |
| Pose seule | Ouvrage fourni ou non, accès, ancrages | Indicatif possible avec bon brief |
| Structure légère | Portée / usage, photos, contraintes site | Visite fréquente si risque |

L'urgence perçue guide le **triage équipe** (qui rappelle en premier). Sur QuoteBuilder, le score Hot / Warm / Cold reste une **formule fixe** (surface, load, access, project_type, constraints, longueur du besoin) : elle ignore photos, zone, urgence et contexte. Elle n'est pas configurable. Pas de SLA produit : vos délais de réponse dépannage sont les vôtres.

## Photos et dimensions : le brief que le téléphone ne remplace pas

Un appel « on veut un portail comme le voisin » sans cote ni photo mène souvent à une visite pour collecter ce que le funnel devait collecter. Demandez au minimum :

- vue d'ensemble de l'ouverture / de l'existant ;
- détail des ancrages / piliers / sol si visibles ;
- contraintes d'accès (cour, étage, passage engins) ;
- pour un escalier : photos des niveaux et de l'emprise approximative.

Rendez l'upload **valorisé** (« avec photos et dimensions approx, réponse plus rapide ») mais pas bloquant : proposez « je n'ai pas de photo ». Voir [pièces jointes / plans / photos](https://www.quotebuilder.co/blog/pieces-jointes-plans-photos-devis-b2b).

## Normes, ERP, sécurité : contexte métier, pas feature produit

Les prospects parlent souvent de « normes », d'ERP ou de garde-corps « aux normes ». Traitez-le comme du **vocabulaire métier** :

- vous pouvez collecter « le prospect mentionne une contrainte ERP / sécurité » ;
- vous ne devez pas présenter QuoteBuilder comme un outil qui calcule une conformité officielle ou remplace un bureau de contrôle ;
- le chiffrage reste le vôtre (fourchette indicative min–max en euros entiers côté produit ; pas de TVA stockée comme feature devis dans QuoteBuilder).

Restez sobres dans les pages marketing et dans le wizard.

## Parcours type : du clic au statut Gagné

1. **Entrée** : funnel site, widget, lien préfill, ou capture orale alignée ([préremplir via URL](https://www.quotebuilder.co/blog/preremplir-devis-url-parametres)).
2. **Brief** : type d'intervention, ouvrage, dimensions approx, accès, photos si possible, besoin rédigé.
3. **Score + owner** : étiquette Hot / Warm / Cold (formule fixe) + triage urgence / zone par l'équipe. Voir [score demande](https://www.quotebuilder.co/blog/score-demande-devis-b2b) et [délai de réponse](https://www.quotebuilder.co/blog/delai-reponse-demande-devis-b2b).
4. **Handoff atelier / pose** : brief complet avant chiffrage ([transfert commercial → technique](https://www.quotebuilder.co/blog/transfert-brief-commercial-technique-devis-b2b)).
5. **Décision visite / relevé** : Hot avec risque réel → relevé court ; Warm → photos / rappel ; Cold → pas de fourgon par défaut ([visite technique avant devis](https://www.quotebuilder.co/blog/visite-technique-avant-devis-b2b)). QuoteBuilder ne planifie pas les tournées.
6. **Chiffrage** : lignes catalogue, options / variantes, fourchette indicative.
7. **Envoi** : lien [espace prospect](https://www.quotebuilder.co/fonctionnalites/espace-prospect). Sur syndic / collectivité / compte pro, invitez les relecteurs (Responsable technique, Directeur financier…). Ils peuvent **Valider le dossier** ou demander des **Modifications** (commentaire + budget max). Chat en fil plat. Pas d'acceptation en ligne inventée : le commercial pose **Gagné**.
8. **Relances** adaptées au score et à l'urgence. Méthode : [relancer un devis Hot](https://www.quotebuilder.co/blog/relancer-devis-hot-depuis-dossier).
9. **Clôture** : **Gagné** ou **Perdu**. Statuts CRM uniquement : Commencée, Nouveau, Contacté, En cours, Gagné, Perdu, En attente.

## Catalogue et options (sans kits ni template inventés)

Côté produit, travaillez avec **options, variantes et produits liés**, pas des « kits / bundles » magiques ni un CTA « Essayer le template métallerie » (il n'existe pas de template secteur métallerie dans QuoteBuilder). Pour démarrer, partez du template **Menuisier**, option « Escalier / garde-corps » ([funnel menuiserie](https://www.quotebuilder.co/secteurs/funnel-devis-menuiserie-sur-mesure)) : vous adaptez les questions, le catalogue reste le vôtre.

Exemples de lignes / options à préparer dans *votre* catalogue :

- dépannage / mise en sécurité ;
- fabrication portail / garde-corps (à décliner selon votre réalité) ;
- pose / dépose / évacuation ;
- finition galva / peinture ;
- option motorisation / contrôle d'accès léger si vous le vendez ;
- option intervention hors heures / site en activité.

Les prix restent les vôtres. Pas de barème national inventé sur la landing.

## Relances typiques (à adapter)

- T+0 (dépannage) : rappel ou créneau sécurisation ;
- T+0 / T+1 (projet) : envoi indicatif ou confirmation de relevé ;
- T+2 j : rappel options (finition / motorisation) ;
- T+5 j : relance Hot avec question précise ;
- puis nurturing ou **Perdu** assumé.

Adaptez selon Hot / Warm / Cold et votre triage urgence. Méthode générale : [pourquoi les devis meurent sans relance](https://www.quotebuilder.co/blog/pourquoi-les-devis-meurent-sans-relance).

## Erreurs fréquentes en métallerie / serrurerie

1. **Traiter toute demande comme un dépannage** (ou l'inverse) : une question « contexte » posée tôt (ordre fixe).
2. **Visiter sans photos ni cotes** : vous payez pour collecter le brief.
3. **Promettre un forfait portail national** sans ouverture ni accès.
4. **Mélanger particulier, pro, syndic et collectivité** sur les mêmes champs.
5. **Présenter normes / ERP comme feature logicielle** : restez sur le contexte métier.
6. **Envoyer sans validation** sur un Hot complexe (accès, gros ouvrage, multi-sites) : voir [validation interne](https://www.quotebuilder.co/blog/validation-interne-avant-envoi-devis-b2b).
7. **Promettre une acceptation en ligne inventée** : espace prospect + relecteurs aident ; le commercial pose **Gagné**.
8. **CTA « Essayer le template métallerie »** : il n'existe pas ; partez du template Menuisier (option « Escalier / garde-corps ») et de votre catalogue.
9. **Un seul PDF forwardé** sur un syndic / Achats : préférez le lien et les invitations relecteurs ([approbation multi-décideurs](https://www.quotebuilder.co/blog/approbation-client-multi-decideurs-devis-b2b)).

## Handoff commercial → atelier / pose

En métallerie, le commercial capture souvent l'intention ; l'atelier chiffre la fabrication ; la pose valide l'accès. Si le brief s'arrête à « portail pour le parking », l'atelier reconstruit, la pose découvre le problème trop tard, et le délai annoncé au prospect vole en éclat.

Process minimal :
1. checklist handoff cochée (ouvrage, cotes approx, accès, photos, finition) ;
2. owner atelier nommé avant promesse de délai ;
3. décision relevé explicite (oui / non / après photos) ;
4. statut CRM clair avant envoi.

Voir le guide dédié : [transfert brief commercial → technique](https://www.quotebuilder.co/blog/transfert-brief-commercial-technique-devis-b2b). Pour chiffrer le coût des mauvais handoffs en interne : [estimateur handoff](https://www.quotebuilder.co/outils/estimateur-cout-handoff-commercial-technique-devis).

## Particularités syndic et collectivité

Sur syndic / collectivité, le brief doit anticiper :
- multi-décideurs (conseil syndical, Achats, AMO) ;
- accès parties communes et créneaux ;
- nécessité d'un lien [espace prospect](https://www.quotebuilder.co/fonctionnalites/espace-prospect) plutôt qu'un PDF forwardé ;
- invitations relecteurs (Valider / Modifications + commentaire + budget max).

Le commercial pose **Gagné** quand la décision est réelle. Pas d'acceptation en ligne inventée. Voir [approbation multi-décideurs](https://www.quotebuilder.co/blog/approbation-client-multi-decideurs-devis-b2b).

## FAQ

### Peut-on chiffrer un portail ou un garde-corps sans visite ?

Souvent un **indicatif** oui, si type d'ouvrage, dimensions approximatives, photos et accès sont corrects. Un devis ferme dépend de votre politique risque (ancrages, sol, surprises chantier).

### Faut-il afficher un prix forfait dépannage serrurerie sur le site ?

Dangereux sans brief. Préférez un parcours qui aboutit à une estimation personnalisée, ou une fourchette très large clairement non contractuelle. Pas de barème « officiel » inventé.

### Comment gérer dépannage et fabrication longue dans le même funnel ?

Branche précoce « contexte ». Triage et délais différents. Même dossier ensuite. Les étapes produit restent en ordre fixe ; vos priorités d'équipe font le reste.

### Comment parler de normes ou d'ERP sans se tromper ?

Mention générique + collecte d'infos + traitement humain. Pas de promesse de conformité automatique dans le wizard, et pas comme feature QuoteBuilder.

### Portail et garde-corps doivent-ils être deux funnels ?

Pas forcément. Une question « type d'ouvrage », dans le même funnel et dans un ordre fixe, suffit souvent. Séparez seulement si les équipes / catalogues sont vraiment distincts.

### Comment éviter l'abandon à l'étape photos ?

Rendez l'upload optionnel mais valorisé. Proposez « je n'ai pas de photo » pour ne pas bloquer. Voir [pièces jointes / plans / photos](https://www.quotebuilder.co/blog/pieces-jointes-plans-photos-devis-b2b).

### QuoteBuilder planifie-t-il les poses métalliers ?

Non. Le produit aide à filtrer et scorer les demandes, chiffrer, partager l'espace prospect et relancer. L'agenda terrain et atelier reste hors produit. Ce n'est pas non plus un client WhatsApp.

### Existe-t-il un template « métallerie » dans QuoteBuilder ?

Non. Il n'y a pas de template secteur métallerie. Le plus proche est le template Menuisier, option « Escalier / garde-corps ». Vous adaptez les questions et vous branchez **votre** catalogue (options, variantes, produits liés).

### Combien d'étapes idéales ?

Souvent 8 à 11. Au-delà, découpez (cœur puis technique) ou repoussez le détail après le score Hot.

### Faut-il une validation interne avant d'envoyer un devis métallerie complexe ?

Sur les Hot / paniers élevés / accès complexes / multi-sites, oui. Ça réduit les devis trop optimistes. Voir [validation interne avant envoi](https://www.quotebuilder.co/blog/validation-interne-avant-envoi-devis-b2b).

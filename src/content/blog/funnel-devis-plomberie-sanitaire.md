# Funnel de devis plomberie et sanitaire : fuite, rénovation, neuf, libellé automatique

Un particulier, un syndic ou un responsable de site ouvre votre page. Il a une fuite, une salle de bain à refaire, ou un lot sanitaire neuf. Il clique sur **Demander un devis**.

Puis il écrit : « Bonjour, tarif plomberie. »

Pas de type d'intervention (fuite / dépannage, rénovation, neuf). Pas de type de pièce. Pas d'accès. Pas de photos. Pas d'urgence réelle vs projet distant. Pas de distinction particulier / pro / syndic. Votre technicien rappelle. On reconstruit le brief. Parfois on se déplace pour découvrir un accès impossible, un projet non voté, ou un devis déjà pris ailleurs. Parfois le prospect a déjà choisi quelqu'un qui avait posé les bonnes questions dès le premier écran.

Ce n'est pas seulement un sujet commercial. C'est un sujet d'**entrée**.

Cette page explique comment un **funnel de devis plomberie / sanitaire** transforme une demande vague en **brief chiffrable** : type d'intervention, type de pièce, accès, photos, urgence, type de client, matériaux / options, puis libellé automatique, espace prospect et statut commercial clair (dont **Gagné** posé par vous). ## Définition : devis plomberie / sanitaire (ce qu'il doit contenir)

Un **devis plomberie** (dépannage, rénovation sanitaire, neuf) est une proposition chiffrée tenant compte au minimum de :

- le **type d'intervention** (fuite / dépannage, rénovation partielle, rénovation complète salle de bain / cuisine, neuf / chantier, entretien / détartrage, « je ne sais pas / conseil ») ;
- le **type de pièce** ou de zone (salle de bain, WC, cuisine, local technique, parties communes, extérieur / regard…) ;
- l'**accès** (appartement, maison, étage, parking, local technique fermé, horaires syndic) ;
- les **photos** (fuite, appareils, arrivées / évacuations visibles, accès) ;
- le **contexte** : urgence vs projet planifié ;
- le **type de client** (particulier, pro / entreprise, syndic / copropriété, bailleur) ;
- les **matériaux / gammes** souhaités si rénovation (entrée / milieu / haut de gamme, ou « à conseiller ») ;
- les **options** (dépose, évacuation gravats, recherche de fuite, mise en sécurité, remplacement appareil, création point d'eau…) ;
- une **mention générique** si le prospect parle d'assurance ou de sinistre (sans inventer de barème ni de prise en charge « officielle »).

Sans type d'intervention, type de pièce et un minimum d'accès / photos, vous n'avez pas un devis : vous avez une fourchette marketing.

## Pourquoi le formulaire contact casse ce secteur

La plomberie cumule urgence (fuite), technique (réseaux, évacuations), accès chantier et parfois multi-décideurs (syndic, conjoint, assureur, responsable site). Un textarea « message » produit :

- des leads hors zone ou hors compétence (industrielle lourde, amiante suspectée, etc.) ;
- des demandes « prix salle de bain » impossibles sans brief ;
- des [visites techniques inutiles](https://www.quotebuilder.co/blog/visite-technique-avant-devis-b2b) faute de photos / accès ;
- des dossiers « urgence » traités comme des projets longs (ou l'inverse) ;
- des allers-retours sur l'assurance (le prospect veut un chiffre garanti, vous ne pouvez pas le coller dans un wizard public).

Le contraste [formulaire contact vs funnel devis B2B](https://www.quotebuilder.co/blog/formulaire-contact-vs-funnel-devis-b2b) s'applique ici avec une friction forte. Les [pièces jointes, plans et photos](https://www.quotebuilder.co/blog/pieces-jointes-plans-photos-devis-b2b) ne sont pas un détail ; elles sont le brief. ## Questions à poser dans le funnel (sans noyer le prospect)

Trop de questions tue la conversion. Trop peu tue le chiffrage. Compromis fréquent pour un plombier / entreprise sanitaire :

### Étape cœur (obligatoire)

1. Type de client : particulier, entreprise, syndic / copropriété, bailleur / autre.
2. Contexte : urgence fuite / panne, rénovation partielle, rénovation complète, neuf / chantier, entretien, « je ne sais pas / conseil ».
3. Type de pièce / zone : salle de bain, WC, cuisine, local technique, parties communes, autre.
4. Accès : maison, appartement (étage), local fermé, horaires contraints, « je ne sais pas ».
5. Code postal (zone d'intervention).
6. Délai souhaité (urgent / sous 48 h / sous 2 semaines / projet distant / vote syndic).
7. Photos de la zone / de la fuite / des appareils, ou « je n'ai pas encore de photo ».

### Étape technique (secondaire, ou une fois le libellé posé)

- Nature du problème (fuite apparente, pression, évacuation, appareil HS, création point d'eau…).
- Appareils concernés (lavabo, douche, baignoire, WC, chauffe-eau, robinetterie…).
- Matériaux / niveau de finition souhaité (si rénovation) : entrée / milieu / haut, ou à conseiller.
- Dépose / évacuation : oui / non / à étudier.
- Contexte assurance / sinistre : oui / non / je ne sais pas (collecte, pas de montage juridique dans le wizard).
- Présence d'un décideur le jour d'une éventuelle visite : oui / non / à confirmer.

### Étape contact

Identité, téléphone, créneau de rappel. Pour du B2B / syndic : SIRET si utile, site, contact technique, éventuel conseil syndical / AMO.

Les options non choisies restent proposables plus tard en [variante](https://www.quotebuilder.co/blog/options-variantes-alternatives-devis-b2b), sans réécrire tout le devis.

## Urgence fuite vs rénovation vs neuf : trois vitesses, un funnel

Ne créez pas trois sites. Posez une **question « contexte »** tôt, dans un ordre fixe. La réponse aide l'équipe à trier l'urgence et le délai de réponse, hors QuoteBuilder. Elle ne change pas l'ordre des questions. QuoteBuilder pose à part un libellé automatique Hot, Warm ou Cold, calculé sur les réponses du formulaire. Ce libellé n'est pas configurable.

| Réponse à « contexte » | Priorité du brief | Suite typique |
|---------|-----------------|---------------|
| Urgence fuite / dépannage | Photos + localisation + accès + créneau rappel court | Mise en sécurité / dépannage puis devis complémentaire si besoin |
| Rénovation partielle | Pièce, photos, accès, niveau finition | Indicatif ou visite ciblée, décidée dans l'équipe |
| Rénovation complète | Pièce(s), matériaux, dépose, délai, décideur | Étude + devis + options |
| Neuf / chantier | Plans, lots, planning chantier | Chiffrage catalogue / forfaits + hypothèses |
| Entretien | Appareil / zone, accès | Devis plus simple. La priorité se décide dans l'équipe |

Le dossier (validation, envoi, relance) reste le même. L'urgence, la zone et le délai de réponse se trient dans l'équipe, hors QuoteBuilder.

## Assurance, DTU, prix au forfait : ce qu'il ne faut pas inventer

Les prospects demandent souvent : « Combien une salle de bain ? », « C'est pris en charge par l'assurance ? », « Vous avez un forfait fuite ? ».

Dans un funnel public, la posture saine est :

- **ne pas afficher** de barèmes d'assurance ou de grilles « officielles » inventées ;
- **ne pas afficher** de prix forfaitaires nationaux comme vérité (chaque chantier a un accès et un existant) ;
- **mentionner** qu'une visite / un diagnostic peut être nécessaire ;
- **collecter** les infos utiles (sinistre déclaré oui/non, photos, type de client) pour qu'un humain traite ;
- **clarifier** que le devis travaux est distinct d'un montage d'assurance ou d'un rapport d'expertise.

Promettre un montant d'indemnisation ou un prix figé sans brief crée des litiges. Même logique que sur le [funnel couverture / toiture](https://www.quotebuilder.co/secteurs/funnel-devis-couverture-toiture) et le [funnel pompe à chaleur / chauffage](https://www.quotebuilder.co/secteurs/funnel-devis-pompe-chaleur-chauffage) : générique oui, barème inventé non.

### 1. Entrée (Ads, SEO, QR véhicule, partenaires, assureurs)

Landing secteur ou widget. Pas un textarea. Wizard 8-11 étapes max.

### 2. Configuration guidée

Les questions se suivent dans un ordre fixe : type de client (particulier, pro, syndic), contexte, pièce, accès. Les règles Si/Alors servent à suggérer des produits du catalogue (forfaits dépannage, lignes sanitaires, options de dépose). Le commercial retrouve les mêmes lignes en interne. Voir [options et variantes](https://www.quotebuilder.co/blog/options-variantes-alternatives-devis-b2b).

### 3. Libellé automatique, puis tri d'équipe

QuoteBuilder pose un libellé automatique Hot, Warm ou Cold, calculé à partir des réponses du formulaire. Il n'est pas configurable. Photos, zone et urgence ne le font pas varier.

L'équipe, hors produit, trie l'urgence, la zone et le délai de réponse (surtout sur une fuite). Un owner clair aide. Un « juste un prix » hors zone ou un projet non voté sans horizon peut attendre, quelle que soit la pastille.

### 4. Décider la visite (sans module planning magique)

Le funnel ne planifie pas la tournée dans QuoteBuilder. Il aide à décider **si** une visite vaut le coup. Voir [visite technique avant devis B2B](https://www.quotebuilder.co/blog/visite-technique-avant-devis-b2b). Règle simple :

- brief faible → photos / rappel d'abord ;
- photos exploitables → indicatif possible, visite courte si l'équipe voit un risque ;
- urgence réelle / existant douteux → visite prioritaire, décidée dans l'équipe ;
- hors zone ou projet flou → pas de fourgon.

### 5. Chiffrage

Estimateur assemble depuis le catalogue / forfaits. Options visibles (dépose, recherche de fuite, remplacement appareil, création point d'eau). Fourchette ou prix selon votre politique. Mention « sous réserve de visite / diagnostic » quand c'est pertinent.

Côté QuoteBuilder, l'affichage devis reste souvent une fourchette indicative en euros entiers (pas de TVA stockée dans l'app ; le plugin Woo a un réglage Taxes optionnel). Avant envoi, une [validation interne](https://www.quotebuilder.co/blog/validation-interne-avant-envoi-devis-b2b) évite les devis sortis trop tôt.

### 6. Envoi + espace prospect + relecteurs

Lien magique : récap, options, questions, documents (photos, plan si neuf). Le prospect n'a pas à chercher le bon PDF. Voir [envoyer devis lien vs PDF](https://www.quotebuilder.co/blog/envoyer-devis-lien-securise-vs-pdf-email) et [espace prospect](https://www.quotebuilder.co/blog/espace-prospect-devis-en-ligne).

Sur syndic ou compte pro, invitez les relecteurs (Responsable technique, Directeur financier…). Chacun a son propre lien. Ils peuvent **Valider le dossier** ou demander des **Modifications** (commentaire + budget max). Commentaires en fil plat. Pas d'acceptation en ligne inventée comme substitut au closing : le commercial pose le statut **Gagné** quand le deal est clos. « Accepté » n'est qu'un libellé d'espace prospect dans ce cas.

### 7. Relances

Séquence adaptée au libellé automatique Hot, Warm ou Cold. Méthode : [relancer un devis Hot](https://www.quotebuilder.co/blog/relancer-devis-hot-depuis-dossier).

## Photos, accès et visite technique

Le funnel ne remplace pas toujours la visite. Il **filtre** :

- dossiers incomplets ou hors zone → nurturing, décision d'équipe ;
- photos exploitables → chiffrage indicatif puis visite courte si besoin ;
- dossiers complexes (parties communes, accès contraint, sinistre, réseaux anciens) → visite / diagnostic avant devis ferme.

Clarifiez dans le parcours : « devis indicatif sous réserve de visite / diagnostic » vs « devis ferme ». Ça évite les litiges sur l'accès réel ou les découvertes en dépose.

Sans photo d'accès, vous multipliez les déplacements inutiles. ## Matériaux, options et variantes (sans catalogue infini)

Beaucoup d'entreprises proposent plusieurs gammes sanitaires. Évitez un wizard de 40 écrans. Une question « niveau de finition », au même endroit du parcours, plus des options, suffit souvent :

| Cas | Infos critiques |
|------------------|-----------------|
| Dépannage / mise en sécurité | Localisation, photos, accès, urgence |
| Remplacement appareil | Type appareil, photos raccordements, accès |
| Rénovation SDB | Surface / type pièce, dépose, finition, évacuation |
| Création point d'eau | Distance réseaux, accès, plan si possible |
| Lots neufs | Plans, quantités, planning chantier |

Les variantes (option dépose, option recherche de fuite, option haut de gamme) se gèrent mieux en [options / alternatives](https://www.quotebuilder.co/blog/options-variantes-alternatives-devis-b2b) qu'en cinq funnels séparés.

## Indicateurs utiles (équipe)

| Indicateur | Pourquoi |
|------------|----------|
| % briefs complets (type + pièce + photos ou accès) | Qualité d'entrée |
| % visites « inutiles » | Filtrage trop faible |
| Délai moyen lead → premier contact (surtout urgence) | Suivi d'équipe, hors produit |
| Délai visite → envoi devis | Chaleur du dossier |
| Taux Gagné / Perdu sur dossiers visités vs non visités | ROI déplacement |

Pas besoin d'un gadget de plus. Le libellé automatique et quelques ratios suffisent pour piloter. L'urgence reste une règle d'équipe.

## Relances typiques (à adapter)

- T+0 (urgence) : rappel ou créneau dépannage ;
- T+0 / T+1 (projet) : envoi indicatif ou confirmation de visite ;
- T+2 j : rappel options (dépose / finition) ;
- T+5 j : relance avec une question précise ;
- puis nurturing ou **Perdu** assumé.

Adaptez selon le libellé Hot, Warm ou Cold, et selon l'urgence notée à part. Méthode générale : [pourquoi les devis meurent sans relance](https://www.quotebuilder.co/blog/pourquoi-les-devis-meurent-sans-relance).

## Erreurs fréquentes en plomberie / sanitaire

1. **Traiter toute demande comme une urgence** (ou l'inverse) : question « contexte » dès le début, dans l'ordre fixe du parcours.
2. **Visiter sans photos** : vous payez pour collecter le brief.
3. **Promettre un forfait national** sans accès ni existant.
4. **Mélanger particulier, pro et syndic** sur les mêmes champs.
5. **Envoyer sans validation** sur un dossier complexe (accès, sinistre, gros lot) : voir [validation interne](https://www.quotebuilder.co/blog/validation-interne-avant-envoi-devis-b2b).
6. **Promettre une acceptation en ligne inventée** comme substitut au closing : espace prospect + relecteurs aident ; le commercial pose **Gagné**.
7. **Un seul PDF forwardé** sur un syndic : préférez le lien et les invitations relecteurs ([approbation multi-décideurs](https://www.quotebuilder.co/blog/approbation-client-multi-decideurs-devis-b2b)).

## FAQ

### Peut-on chiffrer une rénovation sanitaire sans visite ?

Souvent un **indicatif** oui, si type d'intervention, pièce, photos et accès sont corrects. Un devis ferme dépend de votre politique risque (réseaux, dépose, surprises cloison).

### Faut-il afficher un prix forfait fuite sur le site ?

Dangereux sans brief. Préférez un parcours qui aboutit à une estimation personnalisée, ou une fourchette très large clairement non contractuelle. Pas de barème « officiel » inventé.

### Comment gérer urgence et projet long dans le même funnel ?

Une question « contexte » posée dans un ordre fixe. QuoteBuilder pose un libellé automatique Hot, Warm ou Cold à partir des réponses du formulaire. L'urgence et le délai de réponse se trient dans l'équipe, hors produit. Même dossier ensuite.

### Comment parler d'assurance sans se tromper ?

Mention générique + collecte d'infos + traitement humain. Pas de promesse de prise en charge dans le wizard.

### Fuite et rénovation salle de bain doivent-elles être deux funnels ?

Pas forcément. Une question « type d'intervention » dans le même funnel, dans un ordre fixe, suffit souvent. Séparez seulement si les équipes / catalogues sont vraiment distincts.

### Comment éviter l'abandon à l'étape photos ?

Rendez l'upload optionnel mais valorisé (« avec photos, réponse plus rapide »). Proposez « je n'ai pas de photo » pour ne pas bloquer. Voir [pièces jointes / plans / photos](https://www.quotebuilder.co/blog/pieces-jointes-plans-photos-devis-b2b).

### QuoteBuilder planifie-t-il les tournées plombiers ?

Non. Le produit collecte le brief, pose un libellé automatique Hot, Warm ou Cold, chiffre, partage l'espace prospect et relance. L'agenda terrain, l'urgence et le délai de réponse restent dans l'équipe.

### Combien d'étapes idéales ?

Souvent 8 à 11. Au-delà, découpez (cœur puis technique) ou repoussez le détail une fois le libellé posé.

### Comment démarrer sans refondre tout le site ?

Un widget funnel sur la page « Devis plomberie » + catalogue minimal (forfaits dépannage, quelques lignes sanitaires, options dépose / accès) suffit pour un pilote.

### Faut-il une validation interne avant d'envoyer un devis plomberie complexe ?

Sur les dossiers complexes, les paniers élevés, les accès difficiles et les sinistres, oui. Ça réduit les devis trop optimistes. Voir [validation interne avant envoi](https://www.quotebuilder.co/blog/validation-interne-avant-envoi-devis-b2b).

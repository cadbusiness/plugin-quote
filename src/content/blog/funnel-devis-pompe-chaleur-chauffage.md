# Funnel de devis pompe à chaleur et chauffage : brief, aides, signature

Un particulier ou un syndic ouvre votre site. Il veut une pompe à chaleur, un ballon thermodynamique, parfois le remplacement d’une chaudière gaz avec radiateurs. Il clique sur **Demander un devis**.

Puis il écrit : « Bonjour, prix pour une PAC pour une maison de 120 m². »

Pas de type (air-eau, air-air). Pas d’énergie actuelle. Pas d’isolation. Pas d’accès technique (comble, local, façade). Pas de photos. Pas de délai. Votre technico rappelle. On reconstruit le brief. Parfois on se déplace pour constater que le projet n’est pas chiffrable tel quel. Parfois le prospect a déjà signé chez quelqu’un qui avait posé les bonnes questions dès le premier écran.

Ce n’est pas seulement un sujet commercial. C’est un sujet d’**entrée**.

Cette page explique comment un **funnel de devis pompe à chaleur / chauffage** transforme une demande vague en **brief chiffrable** : puissance indicative, surface, énergie actuelle, isolation, accès technique, mention générique des aides, photos, délai de pose, options, puis espace prospect et signature. Public : installateurs, bureaux d’études thermiques, réseaux et agences qui outillent ces équipes.

## Définition : devis PAC / chauffage (ce qu’il doit contenir)

Un **devis pompe à chaleur / chauffage** est une proposition chiffrée pour un système de production de chaleur (et parfois d’ECS) tenant compte au minimum de :

- le **type de système** (PAC air-eau, PAC air-air, ballon thermodynamique, radiateurs / plancher chauffant associés, éventuellement appoint) ;
- la **surface** chauffée et le type de logement (maison, appartement, local) ;
- l’**énergie actuelle** (gaz, fioul, électrique, déjà PAC) et l’objectif (remplacement, appoint, neuf) ;
- un ordre de grandeur de **puissance** ou de besoins (indicatif tant que l’étude n’est pas faite) ;
- l’**isolation** et le niveau de performance du bâti (même qualitatif : « récent / à isoler / RT2012 / etc. ») ;
- l’**accès technique** (emplacement unité extérieure, local technique, longueur de liaisons, contraintes de façade / voisinage) ;
- le **délai de pose** et le mode d’intervention ;
- les **options** (thermostats, radiateurs additionnels, désembouage, dépose ancienne chaudière, ballon ECS) ;
- une **mention générique des aides** possibles (sans inventer de barème ni promettre un montant) .

Sans surface, typologie et accès, vous n’avez pas un devis : vous avez une fourchette marketing.

## Pourquoi le formulaire contact casse ce secteur

Le chauffage / PAC cumule des contraintes techniques et réglementaires. Un textarea « message » produit :

- des leads hors zone ou hors compétence ;
- des demandes « prix au m² » impossibles à tenir ;
- des allers-retours sur les aides (le prospect veut un chiffre d’aide, vous ne pouvez pas le garantir dans un mail) ;
- des déplacements techniques inutiles.

Le contraste [formulaire contact vs funnel devis B2B](https://www.quotebuilder.co/blog/formulaire-contact-vs-funnel-devis-b2b) s’applique ici avec encore plus de friction : chaque info manquante coûte une heure de technico.

## Questions à poser dans le funnel (sans noyer le prospect)

Trop de questions tue la conversion. Trop peu tue le chiffrage. Compromis fréquent pour un installateur / réseau :

### Étape cœur (obligatoire)

1. Type de besoin : chauffage seul, ECS seule, chauffage + ECS, remplacement chaudière.
2. Système envisagé : PAC air-eau, air-air, ballon thermo, « je ne sais pas / conseil ».
3. Surface chauffée approximative + type de bien.
4. Énergie / système actuel.
5. Isolation / année de construction (qualitatif si besoin).
6. Code postal (zone d’intervention).
7. Délai souhaité (urgent / saison / projet distant).
8. Photos ou « je n’ai pas encore de photo ».

### Étape technique (secondaire, ou après score Hot)

- Accès unité extérieure (jardin, toit, cour, mithoyenneté).
- Local technique existant ou non.
- Émetteurs : radiateurs acier, fonte, plancher, ventilo-convecteurs.
- Dépose / désembouage à prévoir.

### Étape contact

Identité, téléphone, créneau de rappel. Pour du B2B / syndic : SIRET, nombre de logements, contact technique.

Les options non choisies restent proposables plus tard en [variante](https://www.quotebuilder.co/blog/options-variantes-alternatives-devis-b2b), sans réécrire tout le devis.

## Aides et financements : ce qu’il faut dire (et ne pas inventer)

Les prospects demandent souvent : « Combien je touche d’aides ? »

Dans un funnel public, la posture saine est :

- **mentionner** que des aides peuvent exister selon profil, logement et travaux ;
- **ne pas afficher** de barèmes inventés ni de montants « 2026 garantis » ;
- **collecter** les infos utiles (statut occupant, type de logement, revenus si vous avez un parcours dédié et conforme) pour qu’un conseiller traite le dossier ;
- **clarifier** que le devis matériel / pose est distinct du montage d’aides.

Promettre un montant d’aide dans un wizard marketing crée des litiges. Mieux vaut un champ « je souhaite être accompagné sur les aides (oui / non / je ne sais pas) » et un process humain derrière.

## Photos, accès technique et visite

Le funnel ne remplace pas toujours la visite. Il **filtre** :

- dossiers incomplets ou hors zone → Cold / nurturing ;
- dossiers Hot avec photos exploitables → chiffrage indicatif puis visite courte ;
- dossiers complexes (copropriété, façade contrainte, bruit voisinage, électrique insuffisant) → visite avant devis ferme.

Clarifiez dans le parcours : « devis indicatif sous réserve de visite » vs « devis ferme ». Ça évite les litiges sur la puissance réelle ou le coût des liaisons.

## Options fréquentes à proposer (sans 15 écrans)

Regroupez plutôt que de multiplier les étapes :

- dépose chaudière / ballon existant ;
- désembouage circuit ;
- radiateurs additionnels ou remplacement émetteurs ;
- thermostat / régulation ;
- ballon ECS (si pas déjà dans le pack) ;
- support / dalle / plot unité extérieure ;
- prolongation de garantie / contrat entretien (si vous le vendez).

Affichez-les comme options cochables. Le total bouge. Le prospect comprend. Vous évitez le « surprise chantier ».

## Délai de pose, validité et acomptes

Trois leviers à lier :

1. **Validité du devis** (ex. 30 jours) : matériel et planning bougent. Voir [validité / expiration](https://www.quotebuilder.co/blog/validite-expiration-devis-b2b).
2. **Créneau pose** : réservé après signature + acompte, pas sur un devis « peut-être ».
3. **Acompte / échéances** : rassurer trésorerie et commande matériel. Voir [acomptes et échéances](https://www.quotebuilder.co/blog/acomptes-echeances-devis-b2b).

Sans ça, vous bloquez des semaines de planning pour des prospects qui comparent encore chez trois installateurs.

## Espace prospect et signature

Après envoi, le prospect doit pouvoir :

- relire le récap (système, surface, options, total) ;
- poser une question sans relancer un e-mail perdu ;
- déposer une facture d’énergie ou une photo complémentaire ;
- accepter / signer quand c’est le bon moment.

C’est le rôle de l’[espace prospect](https://www.quotebuilder.co/blog/espace-prospect-devis-en-ligne) et de la [signature / acceptation en ligne](https://www.quotebuilder.co/blog/signature-acceptation-devis-en-ligne-b2b). Moins de « vous avez bien reçu mon devis ? ».

## Relances : le devis PAC meurt souvent après l’envoi

Le prospect compare. Il attend un devis concurrent. Il doit valider avec conjoint / syndic / banquier. Sans relance, le dossier refroidit pendant que votre planning se remplit d’autres « peut-être ».

Cadrez une séquence courte :

- T+0 : confirmation + lien espace prospect ;
- T+2 j : rappel options / délai pose restant ;
- T+5 j : rappel validité + proposition créneau visite si besoin.

Adaptez selon le score Hot / Warm / Cold. Méthode générale : [pourquoi les devis meurent sans relance](https://www.quotebuilder.co/blog/pourquoi-les-devis-meurent-sans-relance) et [relancer un devis Hot](https://www.quotebuilder.co/blog/relancer-devis-hot-depuis-dossier).

## Erreurs fréquentes à éviter

1. **Promettre un montant d’aide dans le funnel** : litige assuré.
2. **Prix au m² affiché sans brief** : vous attirez des tireurs de prix.
3. **Ignorer l’accès unité extérieure** : le coût sort au chantier.
4. **Un seul PDF sans suivi** : relances à l’aveugle. Préférez le [lien sécurisé](https://www.quotebuilder.co/blog/envoyer-devis-lien-securise-vs-pdf-email).
5. **Réserver un créneau pose avant signature** : vous bloquez l’équipe pour un comparateur.
6. **Mélanger air-air et air-eau sur le même écran d’options** : le prospect se perd, le devis aussi.

## FAQ

### Peut-on chiffrer une PAC sans visite ?

Souvent un **indicatif** oui, si surface, énergie, photos et accès sont corrects. Un devis ferme dépend de votre politique risque (électrique, liaisons, voisinage, émetteurs).

### Faut-il afficher un prix au m² sur le site ?

Dangereux sans brief. Préférez un parcours qui aboutit à une estimation personnalisée, ou une fourchette très large clairement non contractuelle.

### Comment gérer air-eau vs air-air dans le même funnel ?

Branche précoce « type de système », puis questions spécifiques. Ne mélangez pas les options des deux familles sur le même écran.

### Comment parler des aides sans se tromper ?

Mention générique + collecte d’infos + traitement humain. Pas de barème inventé dans le wizard.

### Les syndics et les particuliers ont-ils le même parcours ?

Même logique, champs différents (lots, contacts, planning). Deux funnels ou une branche « type de client » dès le début.

### Comment éviter l’abandon à l’étape photos ?

Rendez l’upload optionnel mais valorisé (« avec photos, réponse sous 48 h »). Proposez « je n’ai pas de photo » pour ne pas bloquer.

### Quel lien avec le catalogue produits ?

Les gammes / forfaits pose du funnel doivent mapper vos kits / articles. Sinon double saisie. Voir bibliothèque de lignes / kits.

### Combien d’étapes idéales ?

Souvent 7 à 10. Au-delà, découpez (cœur puis technique) ou repoussez le détail après le score Hot.

### Comment démarrer sans refondre tout le site ?

Un widget funnel sur la page « Devis PAC » + catalogue minimal (3 gammes, forfaits pose, 6 options) suffit pour un pilote.

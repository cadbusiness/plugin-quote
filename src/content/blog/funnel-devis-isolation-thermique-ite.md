# Funnel de devis isolation thermique et ITE : façade, combles, brief, relances

Un particulier, un syndic ou un gestionnaire de parc ouvre votre page. Il veut « isoler » : parfois l’ITE (isolation thermique par l’extérieur), parfois les combles, parfois les murs par l’intérieur ou un plancher. Il clique sur **Demander un devis**.

Puis il écrit : « Bonjour, tarif pour isolation maison. »

Pas de type de surface. Pas de m². Pas de support (façade, combles perdus, rampants…). Pas d’accès chantier. Pas d’état existant. Pas de photos. Pas de type de client. Votre technico rappelle. On reconstruit le brief. Parfois on se déplace pour découvrir un ravalement fragile, un accès nacelle obligatoire ou un syndic qui n’a pas encore voté. Parfois le prospect a déjà signé chez quelqu’un qui avait posé les bonnes questions dès le premier écran.

Ce n’est pas seulement un sujet commercial. C’est un sujet d’**entrée**.

Cette page explique comment un **funnel de devis isolation thermique / ITE** transforme une demande vague en **brief chiffrable** : type de travaux, surface, support, accès, état existant, photos, délai, type de client, options, puis espace prospect et relances. Les relecteurs valident le dossier ; le commercial pose Gagné. Public : entreprises d’isolation, façadiers ITE, artisans rénovation énergétique, réseaux et agences qui outillent ces équipes.

## Définition : devis isolation thermique / ITE (ce qu’il doit contenir)

Un **devis isolation thermique** (dont ITE) est une proposition chiffrée pour des travaux d’isolation tenant compte au minimum de :

- le **type de travaux** (ITE façade, isolation combles, murs par l’intérieur, planchers / vides sanitaires, mixte) ;
- le **support** et l’état existant (enduit, bardage, sous-toiture, plancher bois / béton…) ;
- une **surface** approximative (m²) ou un métré indicatif ;
- l’**accès chantier** (échafaudage, nacelle, rue étroite, hauteur) ;
- le **type de client** (particulier, pro, syndic / copropriété, bailleur) ;
- les **photos** ou un plan / croquis utile ;
- le **délai** souhaité et la saisonnalité éventuelle ;
- les **options** (finitions, ventilation associée, reprise points singuliers, échafaudage inclus ou non) ;
- une **mention générique des aides ou dispositifs** éventuellement applicables (sans inventer de barème ni promettre un montant MaPrimeRénov’ ou autre).

Sans type de surface, m² et accès (même approximatifs), vous n’avez pas un devis : vous avez une fourchette marketing.

## Pourquoi le formulaire contact casse ce secteur

L’isolation cumule technique, planning chantier, finitions visibles (surtout en ITE) et attentes « aides / rénovation énergétique ». Un textarea « message » produit :

- des leads hors zone ou hors compétence (hauteur, mitoyenneté, ravalement classé, etc.) ;
- des demandes « prix au m² » impossibles à tenir sans brief ;
- des allers-retours sur les aides (le prospect veut un chiffre garanti, vous ne pouvez pas le coller dans un wizard public) ;
- des déplacements inutiles faute de photos façade / combles / accès.

## Questions à poser dans le funnel (sans noyer le prospect)

Trop de questions tue la conversion. Trop peu tue le chiffrage. Compromis fréquent pour un façadier / entreprise d’isolation :

### Étape cœur (obligatoire)

1. Type de client : particulier, entreprise, syndic / copropriété, bailleur / autre.
2. Type de travaux : ITE / façade, combles, murs intérieurs, planchers, « je ne sais pas / conseil ».
3. Surface approximative (m²) ou « je ne sais pas / à métrer ».
4. Support / état existant (qualitatif) : enduit, bardage, combles perdus / aménagés, etc.
5. Accès chantier : facile, échafaudage, nacelle, contrainte rue / voisinage, hauteur.
6. Code postal (zone d’intervention).
7. Délai souhaité (urgent / saison / projet distant / vote syndic à venir).
8. Photos façade / combles / accès ou « je n’ai pas encore de photo ».

### Étape technique (secondaire, ou après score Hot)

- Nombre de niveaux / hauteur approximative.
- Points singuliers (balcons, tableaux de fenêtres, débords de toit).
- Presence d’amiante / diagnostic connu (qualitatif, sans transformer le funnel en audit).
- Ventilation / étanchéité à l’air : « à étudier » si dans votre offre.
- Finitions souhaitées (enduit, bardage, teinte indicative).

### Étape contact

Identité, téléphone, créneau de rappel. Pour du B2B / syndic : SIRET, site, contact technique, éventuel conseil syndical / AMO.

Les options non choisies restent proposables plus tard en [variante](https://www.quotebuilder.co/blog/options-variantes-alternatives-devis-b2b), sans réécrire tout le devis.

## Aides et financements : ce qu’il faut dire (et ne pas inventer)

Les prospects demandent souvent : « Combien je touche avec MaPrimeRénov’ ? » ou « C’est pris en charge à combien ? »

Dans un funnel public, la posture saine est :

- **mentionner** que des dispositifs ou aides peuvent exister selon profil, type de travaux, performance et réglementation en vigueur ;
- **ne pas afficher** de barèmes inventés ni de montants « garantis » ;
- **collecter** les infos utiles pour qu’un conseiller traite le dossier (statut occupant, type de logement, etc., dans un parcours conforme) ;
- **clarifier** que le devis travaux est distinct du montage d’aides ou de simulations financières détaillées.

Promettre un montant d’aide figé dans un wizard marketing crée des litiges. Mieux vaut un champ « je souhaite être accompagné sur les aides / le financement (oui / non / je ne sais pas) » et un process humain derrière.

Même logique que sur le [funnel photovoltaïque / solaire](https://www.quotebuilder.co/secteurs/funnel-devis-photovoltaique-solaire) et le [funnel pompe à chaleur / chauffage](https://www.quotebuilder.co/secteurs/funnel-devis-pompe-chaleur-chauffage) : générique oui, barème inventé non.

## Photos, accès chantier et visite

Le funnel ne remplace pas toujours la visite / le métré. Il **filtre** :

- dossiers incomplets ou hors zone → Cold / nurturing ;
- dossiers Hot avec photos exploitables → chiffrage indicatif puis visite courte ;
- dossiers complexes (copropriété, hauteur, mitoyenneté, ravalement fragile, amiante suspecté) → visite / étude avant devis ferme.

Clarifiez dans le parcours : « devis indicatif sous réserve de visite / métré » vs « devis ferme ». Ça évite les litiges sur les m² réels, les points singuliers ou le coût d’accès.

Sans photo d’accès, vous multipliez les déplacements inutiles. L’[estimateur coût aller-retours brief / photos](https://www.quotebuilder.co/outils/estimateur-cout-aller-retours-brief-photos) aide à chiffrer cette friction en interne.

## ITE, combles, murs, planchers : une question, pas quatre sites

Beaucoup d’entreprises font plusieurs familles. Évitez quatre landings qui se cannibalisent sans brief commun. Posez le type de travaux dans l’ordre fixe :

| Type de travaux | Infos critiques |
|---------|-----------------|
| ITE / façade | m² façade, hauteur, finition, accès, ouvertures |
| Combles | perdus / aménagés, surface, accès trappe, état sous-toiture |
| Murs intérieurs | pièces concernées, m², finitions, contraintes usage |
| Planchers / vides | type support, accès, hauteur sous plancher |

Le catalogue suggère d’autres produits selon le type. Le libellé automatique, lui, ne change pas. Le process devis (dossier, validation, envoi, relance) reste le même.

## Options fréquentes à proposer (sans 15 écrans)

Regroupez plutôt que de multiplier les étapes :

- finition (enduit / bardage / teinte indicative) ;
- échafaudage / nacelle (inclus, option, ou « selon visite ») ;
- traitement points singuliers (tableaux, débords, balcons) ;
- reprise / préparation support (qualitatif) ;
- ventilation associée (si vous la vendez) ;
- entretien / garantie étendue (si dans votre offre).

Affichez-les comme options cochables. Le total bouge. Le prospect comprend. Vous évitez le « surprise chantier ».

## Délai de pose, durée de prix et acomptes

**Hors QuoteBuilder pour la durée de prix.** Le produit n'affiche pas de validité. Trois leviers d'équipe :

1. **Durée de prix** (ex. 30 jours), hors produit : matériaux et planning bougent. Voir [validité / expiration](https://www.quotebuilder.co/blog/validite-expiration-devis-b2b).
2. **Créneau chantier** : réservé après accord commercial (statut Gagné) et acompte, pas sur un devis « peut-être » (surtout en saison ITE).
3. **Acompte / échéances** : rassurer trésorerie et commande. Voir [acomptes et échéances](https://www.quotebuilder.co/blog/acomptes-echeances-devis-b2b).

Sans ça, vous bloquez des semaines d’échafaudage pour des prospects qui comparent encore chez trois façadiers.

## Espace prospect

Après envoi, le prospect doit pouvoir :

- relire le récap (type de travaux, m² indicatifs, options, total) ;
- poser une question sans relancer un e-mail perdu ;
- déposer une photo complémentaire, un plan ou un document syndic.

Les relecteurs invités répondent par « Valider le dossier » ou « Modifications ». Le commercial pose Gagné. Moins de « vous avez bien reçu mon devis ? ». Voir l’[espace prospect](https://www.quotebuilder.co/fonctionnalites/espace-prospect).

Sur les dossiers syndic, l’espace partagé évite les PDF contradictoires entre conseil syndical et gestionnaire. QuoteBuilder n’a pas de versions : un seul dossier courant. ## Relances : le devis isolation meurt souvent après l’envoi

Le prospect compare. Il attend un vote syndic. Il doit valider avec conjoint / AMO / direction. Sans relance, le dossier refroidit pendant que votre planning se remplit d’autres « peut-être ».

Cadrez une séquence courte :

- T+0 : confirmation + lien espace prospect ;
- T+2 j : rappel options (finition / accès) + créneau visite si besoin ;
- T+5 j : rappel de la durée de prix, hors produit, et prochain créneau chantier indicatif.

Adaptez selon le score Hot / Warm / Cold. Méthode générale : [pourquoi les devis meurent sans relance](https://www.quotebuilder.co/blog/pourquoi-les-devis-meurent-sans-relance) et [relancer un devis Hot](https://www.quotebuilder.co/blog/relancer-devis-hot-depuis-dossier).

## Erreurs fréquentes à éviter

1. **Promettre un montant d’aide figé dans le funnel** : litige assuré.
2. **Prix au m² affiché sans brief** : vous attirez des tireurs de prix.
3. **Ignorer l’accès et la hauteur** : le coût sort au chantier.
4. **Un seul PDF sans suivi** : relances à l’aveugle. Préférez le [lien sécurisé](https://www.quotebuilder.co/blog/envoyer-devis-lien-securise-vs-pdf-email).
5. **Réserver un créneau échafaudage avant que le commercial pose Gagné** : vous bloquez l’équipe pour un comparateur.
6. **Mélanger particulier, pro et syndic sur les mêmes champs** : posez « type de client » dans l’ordre fixe, dès le début.
7. **Envoyer sans validation technique** sur un Hot ITE complexe : V2 garantie. Voir [validation interne](https://www.quotebuilder.co/blog/validation-interne-avant-envoi-devis-b2b).

## FAQ

### Peut-on chiffrer une ITE sans visite ?

Souvent un **indicatif** oui, si surface, hauteur, photos façade et accès sont corrects. Un devis ferme dépend de votre politique risque (support, points singuliers, mitoyenneté, diagnostics).

### Faut-il afficher un prix au m² sur le site ?

Dangereux sans brief. Préférez un parcours qui aboutit à une estimation personnalisée, ou une fourchette très large clairement non contractuelle.

### Comment gérer particulier, pro et syndic dans le même funnel ?

Posez « type de client » dans l’ordre fixe, puis SIRET, lots, contact technique, vote AG. Ne mélangez pas tout sur le même écran. Les règles Si/Alors suggèrent les produits.

### Comment parler des aides sans se tromper ?

Mention générique + collecte d’infos + traitement humain. Pas de barème inventé (MaPrimeRénov’ ou autre) dans le wizard.

### Combles et ITE doivent-ils être deux funnels séparés ?

Pas forcément. Posez le type de travaux dans le même parcours, dans un ordre fixe. Les règles Si/Alors suggèrent les produits. Séparez seulement si les équipes ou les catalogues sont vraiment distincts.

### Comment éviter l’abandon à l’étape photos ?

Rendez l’upload optionnel mais valorisé (« avec photos façade / combles, réponse sous 48 h »). Proposez « je n’ai pas de photo » pour ne pas bloquer. Voir aussi [pièces jointes / plans / photos](https://www.quotebuilder.co/blog/pieces-jointes-plans-photos-devis-b2b).

### Quel lien avec le catalogue produits ?

Les gammes isolants, finitions et forfaits pose du funnel doivent mapper vos options, variantes et produits liés. Pas de kits. Sinon double saisie des lignes. Voir bibliothèque de lignes.

### Combien d’étapes idéales ?

Souvent 8 à 11. Au-delà, découpez (cœur puis technique) ou repoussez le détail après le score Hot.

### Comment démarrer sans refondre tout le site ?

Un widget funnel sur la page « Devis isolation / ITE » + catalogue minimal (2-3 gammes, forfaits pose, options accès / finition) suffit pour un pilote.

### Faut-il une validation interne avant d’envoyer un devis ITE ?

Sur les Hot / paniers élevés / accès complexes, oui. Ça réduit les V2 et les remises de panique.
